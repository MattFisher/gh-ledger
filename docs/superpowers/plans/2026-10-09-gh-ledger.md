# gh-ledger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `gh-ledger`, a CLI that fetches one GitHub user's activity over a long period into CSV tables, aggregates it into per-period metrics, and renders a self-contained HTML report with PNG/SVG charts, event overlays and AI-assistance shares.

**Architecture:** Three stages, each reading only the previous stage's files on disk: `fetch` (GitHub REST + GraphQL → `DIR/*.csv` + `DIR/manifest.json`, with a response cache in `DIR/cache/`), `summary` (CSV → `DIR/metrics.csv` in long format plus a terminal table), `report` (metrics → `OUT/report.html` + `OUT/charts/*.{png,svg}`). Row dataclasses in `model.py` are the schema contract between stages.

**Tech Stack:** Python 3.12, uv (with the `uv_build` backend), scriv changelog fragments, httpx, typer, rich, pandas, plotly, pyyaml, kaleido (optional extra), pytest with `httpx.MockTransport`, basedpyright (strict), ruff, pre-commit. Scaffolded with Copier from `MattFisher/python-project-template`.

**Spec:** `docs/superpowers/specs/2026-10-09-gh-ledger-design.md`

## Global Constraints

- Template: `gh:MattFisher/python-project-template` (the author's instruction overrides the spec's `Generality-Labs/...` reference), answered as a **library** with `github_owner=MattFisher`, MIT licence, PyPI trusted publishing scaffolded.
- `requires-python = ">=3.12"`.
- Runtime dependencies: httpx, typer, pandas, plotly, pyyaml, plus rich (imported directly; typer already depends on it). kaleido is only in the optional extra `gh-ledger[images]` (and in the dev group for tests).
- Console script: `gh-ledger = "gh_ledger.cli:app"`.
- Commands and flags exactly as the spec's Architecture block: `fetch --user U --since DATE [--until DATE] [--visibility public|all] [--author-email E]... [--refresh] --data DIR`, `summary --data DIR [--period week|month|quarter] [--config ledger.toml]`, `report --data DIR --out DIR [--config ledger.toml] [--events FILE]... [--redact-private]`.
- Timestamps in CSVs: UTC ISO 8601, `YYYY-MM-DDTHH:MM:SSZ`. List columns (`co_authors`) are `;`-separated. Booleans are `true`/`false`. Missing values are empty strings.
- Table keys: GitHub node IDs, commit SHAs for `commits.csv`, `(source, source_id)` for `file_changes.csv`.
- Search windows start at one calendar month and bisect while `total_count > 1000`.
- Cache: search windows ending more than 30 days before now are never re-fetched; newer windows are re-fetched every run; merged/closed PR details and commit file lists are never re-fetched; open PR details are re-fetched every run; `--refresh` re-fetches everything.
- Search calls are spaced to stay under 30 per minute. 5xx retries 3 times with exponential backoff. Secondary limits honour `Retry-After`. Primary-limit exhaustion sleeps until `X-RateLimit-Reset` with a countdown.
- `per_file_cap` default 1000; `top_repos` default 8; `image_size` default `[1200, 600]`; `period` default `month`.
- CI never calls the live API. The one live test carries the `live` marker and is deselected by default.
- `data/` is gitignored: with `--visibility all`, the data directory holds private text.
- The public GitHub repo `MattFisher/gh-ledger` is created **only after the author confirms**. No PyPI release in this plan.
- basedpyright runs in strict mode on `src`. Modules built mostly on pandas/plotly start with `# pyright: basic` because those libraries leave too many partially unknown types for strict mode.

## Review Focus

These five input classes are implied by the spec, but none of its listed tests cover them. They are the ones most likely to hurt a real user. Each has a pinned test in the task named.

1. **Re-fetching into a DIR that holds a different user's data, or data fetched with a different `--visibility`.** Expected: the fetch is refused with a message naming the mismatch, and nothing is written. Without this, two users' data would mix, or private rows would survive in a dataset now labelled public. Tests: Task 11, `test_refuses_directory_of_other_user` and `test_refuses_visibility_change`.
2. **A user with no activity in the range (every CSV is header-only).** Expected: `summary` writes zero counts for every period, leaves AI shares empty, and `report` renders every chart without crashing. Tests: Task 14 `test_no_activity_gives_zero_counts_and_empty_shares`, Task 17 `test_report_with_no_activity`.
3. **Malformed user files: an invalid regex in `[ai].patterns`, a mistyped key in `ledger.toml`, an event missing its `date`.** Expected: a one-line error naming the file and key, exit code 1, and no traceback. Tests: Task 13 (config cases), Task 15 (event cases), Task 17 `test_report_bad_events_file_exits_cleanly`.
4. **Deleted accounts and vanished repos.** A ghost author shows up as `author: null`, and a commit can point at a repo that now 404s. Expected: rows are kept with an empty author (which counts as "someone else's"), and the gone repo is skipped and listed in the manifest. Tests: Task 8 `test_ghost_pr_author_is_empty`, Task 9 `test_ghost_parent_author_is_empty`, Task 10 `test_vanished_repo_is_skipped_and_recorded`, Task 14 `test_reviews_on_ghost_prs_count_as_others`.
5. **Timestamps with non-UTC offsets near a period boundary.** Commit search returns author dates with local offsets. Expected: a commit at `2024-01-31T23:30:00-05:00` is stored as `2024-02-01T04:30:00Z` and counted in February. Test: Task 10 `test_author_dates_are_normalised_to_utc`.

## Decisions This Plan Makes Where the Spec Is Silent

- Template owner is `MattFisher`, so CI calls `MattFisher/python-project-template/.github/workflows/python-ci.yml@v1`. That tag exists; the template is at v1.8.1.
- `file_changes.date` is `merged_at` for merged PRs and `created_at` for unmerged ones. Only unmerged PRs need it, and they only count when `count_unmerged_pr_lines = true`.
- Conversation comments (`user.issueComments`) are a newest-first stream with no date windows, so they are never cached and are re-read every run back to `--since`.
- PR and commit `text` is the body (PRs) or message (commits). A PR's text also includes all its commit messages, so trailers and "Generated with" lines anywhere in the PR count as AI markers.
- `top_repos` is capped at 8, one categorical colour per repo. The rest fold into "other".
- The `lines` chart draws raw additions and raw deletions as two faint lines sharing one legend entry ("Before filters"), mirroring the positive and negative bars.
- `compare` puts a period that straddles `compare_at` in "before" when it starts before `compare_at`.
- `--visibility` defaults to `public`. `--config` has no implicit default file.
- Fetch tests serve GitHub responses through `httpx.MockTransport` as the spec says. The responses come from small factories in `tests/github_fakes.py`, shaped on the samples the Task 1 probe saved, not from verbatim recordings: recordings would carry real (possibly private) text and be hard to read in review.
- Paths in `ledger.toml` exclusions follow a subset of `.gitignore` semantics, documented in `filters.PathFilter`.

```python
"""Throwaway probe of the GitHub API behaviour gh-ledger's design relies on.

Run: uv run --no-project --with httpx python /tmp/gh-ledger-probe/probe.py --other jjallaire
"""

import argparse
import json
import subprocess
from collections import Counter
from datetime import UTC, datetime, timedelta
from pathlib import Path

import httpx

OUT = Path(__file__).parent / "out"

ISSUE_COMMENTS = """
query($login: String!, $after: String) {
  user(login: $login) {
    issueComments(first: 100, after: $after, orderBy: {field: UPDATED_AT, direction: DESC}) {
      totalCount
      pageInfo { hasNextPage endCursor }
      nodes {
        id createdAt updatedAt url
        issue { number url author { login } }
        pullRequest { number url author { login } }
        repository { nameWithOwner isPrivate isFork }
      }
    }
  }
}"""

REVIEWS = """
query($login: String!, $from: DateTime!, $to: DateTime!, $after: String) {
  user(login: $login) {
    contributionsCollection(from: $from, to: $to) {
      totalPullRequestReviewContributions
      restrictedContributionsCount
      hasAnyRestrictedContributions
      pullRequestReviewContributions(first: 100, after: $after) {
        totalCount
        pageInfo { hasNextPage endCursor }
        nodes {
          occurredAt
          pullRequestReview {
            id state submittedAt body url
            comments(first: 100) { totalCount nodes { id createdAt body url } }
          }
          pullRequest { number url author { login } }
          repository { nameWithOwner isPrivate isFork }
        }
      }
    }
  }
}"""

COUNT = "query($q: String!) { search(type: ISSUE, query: $q, first: 1) { issueCount } }"

PR_SEARCH = """
query($q: String!) {
  rateLimit { cost remaining }
  search(type: ISSUE, query: $q, first: 50) {
    issueCount
    nodes { ... on PullRequest {
      id number state changedFiles additions deletions
      files(first: 100) { totalCount nodes { path additions deletions changeType } }
      commits(first: 100) { totalCount nodes { commit { message } } }
    } }
  }
}"""


class GitHub:
    def __init__(self) -> None:
        token = subprocess.run(
            ["gh", "auth", "token"], check=True, capture_output=True, text=True
        ).stdout.strip()
        self.http = httpx.Client(
            base_url="https://api.github.com",
            timeout=60,
            headers={
                "Authorization": f"Bearer {token}",
                "Accept": "application/vnd.github+json",
                "X-GitHub-Api-Version": "2022-11-28",
            },
        )

    def gql(self, query: str, variables: dict) -> dict:
        body = self.http.post("/graphql", json={"query": query, "variables": variables}).json()
        if body.get("errors"):
            print("  GraphQL errors:", json.dumps(body["errors"])[:400])
        return body.get("data") or {}

    def get(self, path: str, **params: object) -> httpx.Response:
        return self.http.get(path, params=params)


def dump(name: str, data: object) -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    (OUT / f"{name}.json").write_text(json.dumps(data, indent=2))


def iso(moment: datetime) -> str:
    return moment.strftime("%Y-%m-%dT%H:%M:%SZ")


def probe_issue_comments(gh: GitHub, login: str) -> None:
    print(f"\n== issueComments: {login}")
    nodes: list[dict] = []
    after = None
    total = 0
    for _ in range(3):
        conn = gh.gql(ISSUE_COMMENTS, {"login": login, "after": after})["user"]["issueComments"]
        total = conn["totalCount"]
        nodes += conn["nodes"]
        if not conn["pageInfo"]["hasNextPage"]:
            break
        after = conn["pageInfo"]["endCursor"]
    dump(f"issue_comments_{login}", nodes)
    updated = [n["updatedAt"] for n in nodes]
    print("  totalCount:", total, "fetched:", len(nodes))
    print("  updatedAt non-increasing:", all(a >= b for a, b in zip(updated, updated[1:])))
    print("  newest/oldest updatedAt:", updated[:1], updated[-1:])
    print("  on PRs:", sum(n["pullRequest"] is not None for n in nodes),
          "on issues:", sum(n["pullRequest"] is None for n in nodes))
    pr_nodes = [n for n in nodes if n["pullRequest"]]
    if pr_nodes:
        print("  PR comment issue.url sample:", pr_nodes[0]["issue"]["url"],
              "pullRequest.url:", pr_nodes[0]["pullRequest"]["url"])
    print("  private:", sum(n["repository"]["isPrivate"] for n in nodes),
          "fork:", sum(n["repository"]["isFork"] for n in nodes))
    print("  edited (createdAt != updatedAt):", sum(n["createdAt"] != n["updatedAt"] for n in nodes))
    print("  null issue author:", sum(n["issue"]["author"] is None for n in nodes))


def probe_reviews(gh: GitHub, login: str) -> None:
    print(f"\n== contributionsCollection reviews: {login}")
    to = datetime.now(UTC).replace(microsecond=0)
    start = to - timedelta(days=365)
    nodes: list[dict] = []
    after = None
    coll: dict = {}
    while True:
        data = gh.gql(REVIEWS, {"login": login, "from": iso(start), "to": iso(to), "after": after})
        coll = data["user"]["contributionsCollection"]
        conn = coll["pullRequestReviewContributions"]
        nodes += conn["nodes"]
        if not conn["pageInfo"]["hasNextPage"] or len(nodes) >= 500:
            break
        after = conn["pageInfo"]["endCursor"]
    dump(f"reviews_{login}", nodes)
    print("  totalPullRequestReviewContributions:", coll["totalPullRequestReviewContributions"])
    print("  restrictedContributionsCount:", coll["restrictedContributionsCount"],
          "hasAnyRestricted:", coll["hasAnyRestrictedContributions"])
    print("  states:", dict(Counter(n["pullRequestReview"]["state"] for n in nodes)))
    own = sum(
        1 for n in nodes
        if ((n["pullRequest"]["author"] or {}).get("login") or "").lower() == login.lower()
    )
    print("  reviews on own PRs:", own, "of", len(nodes))
    print("  with body:", sum(bool(n["pullRequestReview"]["body"]) for n in nodes))
    print("  inline comments total:", sum(n["pullRequestReview"]["comments"]["totalCount"] for n in nodes))
    print("  reviews with >100 inline comments:",
          sum(n["pullRequestReview"]["comments"]["totalCount"] > 100 for n in nodes))
    print("  private:", sum(n["repository"]["isPrivate"] for n in nodes),
          "fork:", sum(n["repository"]["isFork"] for n in nodes))
    distinct = {n["pullRequest"]["url"] for n in nodes
                if ((n["pullRequest"]["author"] or {}).get("login") or "").lower() != login.lower()}
    q = f"is:pr reviewed-by:{login} -author:{login} updated:>={start:%Y-%m-%d}"
    searched = gh.gql(COUNT, {"q": q})["search"]["issueCount"]
    print("  distinct others' PRs reviewed (contributions):", len(distinct),
          "| search reviewed-by (upper bound):", searched)
    over = gh.gql(REVIEWS, {"login": login, "from": iso(to - timedelta(days=400)), "to": iso(to), "after": None})
    print("  400-day span accepted:", bool(over))


def probe_shapes(gh: GitHub, login: str) -> None:
    print(f"\n== PR search + commit search shapes: {login}")
    end = datetime.now(UTC).date().replace(day=1) - timedelta(days=1)
    start = end.replace(day=1)
    window = f"{start}T00:00:00+00:00..{end}T23:59:59+00:00"
    with_time = gh.gql(COUNT, {"q": f"is:pr author:{login} created:{window}"})["search"]["issueCount"]
    date_only = gh.gql(COUNT, {"q": f"is:pr author:{login} created:{start}..{end}"})["search"]["issueCount"]
    print("  created: with +00:00 times:", with_time, "| date-only:", date_only)
    data = gh.gql(PR_SEARCH, {"q": f"is:pr author:{login} created:{window}"})
    dump(f"pr_search_{login}", data)
    print("  PR search issueCount:", data["search"]["issueCount"], "rateLimit:", data["rateLimit"])
    for pr in data["search"]["nodes"][:5]:
        print("   PR", pr["number"], pr["state"], "changedFiles", pr["changedFiles"],
              "files.totalCount", pr["files"]["totalCount"], "commits", pr["commits"]["totalCount"])
    resp = gh.get("/search/commits", q=f"author:{login} author-date:{window}", per_page=20)
    print("  commit search status:", resp.status_code)
    items = resp.json().get("items", [])
    print("  total_count:", resp.json().get("total_count"))
    if not items:
        return
    first = items[0]
    print("  item keys:", sorted(first))
    print("  repository private/fork present:", "private" in first["repository"], "fork" in first["repository"])
    print("  author date sample:", first["commit"]["author"]["date"])
    parts = []
    for i, item in enumerate(items):
        owner, name = item["repository"]["full_name"].split("/", 1)
        parts.append(
            f'c{i}: repository(owner: {json.dumps(owner)}, name: {json.dumps(name)}) '
            f'{{ object(oid: "{item["sha"]}") {{ ... on Commit {{ associatedPullRequests(first: 1) '
            f"{{ totalCount }} }} }} }}"
        )
    assoc = gh.gql("query CommitAssociations {\n" + "\n".join(parts) + "\n}", {})
    attached = sum(
        1 for v in assoc.values()
        if v and v["object"] and v["object"]["associatedPullRequests"]["totalCount"]
    )
    print("  commits attached to a PR:", attached, "of", len(items))
    for item in items:
        path = f"/repos/{item['repository']['full_name']}/commits/{item['sha']}"
        full = gh.get(path).json()
        if len(full.get("files", [])) >= 2:
            paged = gh.get(path, per_page=1, page=2)
            print("  commit", item["sha"][:7], "files:", len(full["files"]),
                  "| per_page=1&page=2 files:", len(paged.json().get("files", [])),
                  "stats:", full["stats"])
            break


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--other", required=True, help="Another active public user")
    args = parser.parse_args()
    gh = GitHub()
    me = gh.gql("query { viewer { login } }", {})["viewer"]["login"]
    for login in (me, args.other):
        probe_issue_comments(gh, login)
        probe_reviews(gh, login)
    probe_shapes(gh, me)


if __name__ == "__main__":
    main()
```

```python
"""Row types for the CSV tables.

These dataclasses are the schema contract between `fetch` and the later stages:
column names and order come from the field order here.
"""

from __future__ import annotations

import dataclasses
from dataclasses import dataclass, field
from typing import TYPE_CHECKING, cast

if TYPE_CHECKING:
    from _typeshed import DataclassInstance


@dataclass(frozen=True)
class RepoRow:
    repo: str
    is_private: bool
    is_fork: bool


@dataclass(frozen=True)
class PrRow:
    id: str
    repo: str
    number: int
    url: str
    title: str
    state: str  # open | closed | merged
    created_at: str
    merged_at: str | None
    closed_at: str | None
    additions: int
    deletions: int
    changed_files: int
    files_truncated: bool
    text: str  # body, then every commit message
    co_authors: tuple[str, ...]


@dataclass(frozen=True)
class IssueRow:
    id: str
    repo: str
    number: int
    url: str
    title: str
    state: str  # open | closed
    created_at: str
    closed_at: str | None
    text: str


@dataclass(frozen=True)
class ReviewRow:
    id: str
    repo: str
    pr_number: int
    pr_url: str
    pr_author: str  # empty for deleted accounts
    state: str  # approved | changes_requested | commented | dismissed
    submitted_at: str
    text: str


@dataclass(frozen=True)
class CommentRow:
    id: str
    repo: str
    kind: str  # issue | pr_conversation | review_inline
    parent_number: int
    parent_url: str
    parent_author: str  # empty for deleted accounts
    created_at: str
    text: str


@dataclass(frozen=True)
class CommitRow:
    sha: str
    repo: str
    authored_at: str
    additions: int
    deletions: int
    files_truncated: bool
    text: str
    co_authors: tuple[str, ...]


@dataclass(frozen=True)
class FileChangeRow:
    source: str  # pr | commit
    source_id: str  # PR node ID or commit SHA
    repo: str
    path: str
    additions: int
    deletions: int
    change_type: str
    date: str  # merged_at for merged PRs, created_at for unmerged PRs, authored_at for commits


@dataclass(frozen=True)
class TableSpec:
    name: str
    row_type: type[DataclassInstance]
    key: tuple[str, ...]


TABLES: tuple[TableSpec, ...] = (
    TableSpec("repos", RepoRow, ("repo",)),
    TableSpec("prs", PrRow, ("id",)),
    TableSpec("issues", IssueRow, ("id",)),
    TableSpec("reviews", ReviewRow, ("id",)),
    TableSpec("comments", CommentRow, ("id",)),
    TableSpec("commits", CommitRow, ("sha",)),
    # Keyed by group: re-fetching a PR replaces its whole file list.
    TableSpec("file_changes", FileChangeRow, ("source", "source_id")),
)


@dataclass
class FetchResult:
    """Everything one fetch run collected, before it is written."""

    repos: list[RepoRow] = field(default_factory=list[RepoRow])
    prs: list[PrRow] = field(default_factory=list[PrRow])
    issues: list[IssueRow] = field(default_factory=list[IssueRow])
    reviews: list[ReviewRow] = field(default_factory=list[ReviewRow])
    comments: list[CommentRow] = field(default_factory=list[CommentRow])
    commits: list[CommitRow] = field(default_factory=list[CommitRow])
    file_changes: list[FileChangeRow] = field(default_factory=list[FileChangeRow])
    dropped_pr_commits: int = 0
    skipped_repos: list[str] = field(default_factory=list[str])
    restricted_contributions: int = 0

    def extend(self, other: FetchResult) -> None:
        self.repos.extend(other.repos)
        self.prs.extend(other.prs)
        self.issues.extend(other.issues)
        self.reviews.extend(other.reviews)
        self.comments.extend(other.comments)
        self.commits.extend(other.commits)
        self.file_changes.extend(other.file_changes)
        self.dropped_pr_commits += other.dropped_pr_commits
        self.skipped_repos.extend(other.skipped_repos)
        self.restricted_contributions += other.restricted_contributions

    def rows(self, table: str) -> list[DataclassInstance]:
        return cast("list[DataclassInstance]", getattr(self, table))


@dataclass
class Manifest:
    user: str
    since: str  # YYYY-MM-DD
    until: str  # YYYY-MM-DD
    visibility: str  # public | all
    fetched_at: str
    tool_version: str
    author_emails: list[str] = field(default_factory=list[str])
    dropped_pr_commits: int = 0
    skipped_repos: list[str] = field(default_factory=list[str])
    restricted_contributions: int = 0


def columns(row_type: type[DataclassInstance]) -> list[str]:
    return [f.name for f in dataclasses.fields(row_type)]


def to_csv_row(row: DataclassInstance) -> dict[str, str]:
    return {f.name: _format(getattr(row, f.name)) for f in dataclasses.fields(row)}


def _format(value: object) -> str:
    if value is None:
        return ""
    if isinstance(value, bool):
        return "true" if value else "false"
    if isinstance(value, tuple):
        return ";".join(str(item) for item in cast("tuple[object, ...]", value))
    return str(value)
```

```python
# pyright: basic
# pandas leaves too many partially-unknown types for strict mode.
"""CSV tables and the manifest on disk."""

from __future__ import annotations

import csv
import dataclasses
import json
from collections.abc import Iterable, Sequence
from pathlib import Path

import pandas as pd

from gh_ledger.model import TABLES, FetchResult, Manifest, columns, to_csv_row

# PR text includes every commit message, which can pass the csv module's 128 KiB default.
csv.field_size_limit(2**31 - 1)

MANIFEST = "manifest.json"


class StoreError(Exception):
    """A data file is missing or does not match the expected schema."""


def upsert_table(
    path: Path, fieldnames: Sequence[str], key: Sequence[str], rows: Iterable[dict[str, str]]
) -> int:
    """Merge rows into a CSV. Existing rows sharing a key with any new row are replaced.

    Returns the number of rows written.
    """
    new_rows = list(rows)
    new_keys = {tuple(row[k] for k in key) for row in new_rows}
    kept: list[dict[str, str]] = []
    if path.exists():
        with path.open(newline="", encoding="utf-8") as handle:
            reader = csv.DictReader(handle)
            if reader.fieldnames != list(fieldnames):
                raise StoreError(
                    f"{path} has columns {reader.fieldnames}, expected {list(fieldnames)}"
                )
            kept = [row for row in reader if tuple(row[k] for k in key) not in new_keys]
    merged = sorted([*kept, *new_rows], key=lambda row: tuple(row[k] for k in key))
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    with tmp.open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=list(fieldnames))
        writer.writeheader()
        writer.writerows(merged)
    tmp.replace(path)
    return len(merged)


def write_tables(data_dir: Path, result: FetchResult) -> None:
    """Upsert every table, writing header-only files for tables with no rows."""
    for spec in TABLES:
        upsert_table(
            data_dir / f"{spec.name}.csv",
            columns(spec.row_type),
            spec.key,
            (to_csv_row(row) for row in result.rows(spec.name)),
        )


def load_table(data_dir: Path, name: str) -> pd.DataFrame:
    """Read one table with every column as str and empty cells as ''."""
    path = data_dir / f"{name}.csv"
    if not path.exists():
        raise StoreError(f"{path} not found; run `gh-ledger fetch` first")
    return pd.read_csv(path, dtype=str, keep_default_na=False)


def load_tables(data_dir: Path) -> dict[str, pd.DataFrame]:
    return {spec.name: load_table(data_dir, spec.name) for spec in TABLES}


def read_manifest(data_dir: Path) -> Manifest | None:
    path = data_dir / MANIFEST
    if not path.exists():
        return None
    return Manifest(**json.loads(path.read_text(encoding="utf-8")))


def write_manifest(data_dir: Path, manifest: Manifest) -> None:
    data_dir.mkdir(parents=True, exist_ok=True)
    text = json.dumps(dataclasses.asdict(manifest), indent=2) + "\n"
    (data_dir / MANIFEST).write_text(text, encoding="utf-8")
```

```python
import os
import subprocess
from collections.abc import Callable, Mapping

class AuthError(Exception):
    """No usable GitHub token."""


def get_token(
    env: Mapping[str, str] | None = None,
    run: Callable[..., subprocess.CompletedProcess[Any]] = subprocess.run,
) -> str:
    env = os.environ if env is None else env
    token = env.get("GITHUB_TOKEN", "").strip()
    if token:
        return token
    try:
        proc = run(["gh", "auth", "token"], capture_output=True, text=True, check=False)
    except FileNotFoundError:
        proc = None
    if proc is not None and proc.returncode == 0 and str(proc.stdout).strip():
        return str(proc.stdout).strip()
    raise AuthError("No GitHub token: set GITHUB_TOKEN or run `gh auth login`.")
```

```python
"""On-disk cache of API responses, keyed by request."""

from __future__ import annotations

import hashlib
import json
from pathlib import Path
from typing import Any


class ResponseCache:
    def __init__(self, root: Path) -> None:
        self._root = root

    @staticmethod
    def key(method: str, url: str, body: str) -> str:
        return hashlib.sha256(f"{method}\n{url}\n{body}".encode()).hexdigest()

    def _path(self, key: str) -> Path:
        return self._root / key[:2] / f"{key}.json"

    def get(self, key: str) -> Any | None:
        try:
            return json.loads(self._path(key).read_text(encoding="utf-8"))
        except FileNotFoundError:
            return None
        except json.JSONDecodeError:
            return None  # torn write from an interrupted run: fetch again

    def put(self, key: str, value: Any) -> None:
        path = self._path(key)
        path.parent.mkdir(parents=True, exist_ok=True)
        tmp = path.with_suffix(".tmp")
        tmp.write_text(json.dumps(value), encoding="utf-8")
        tmp.replace(path)
```

```python
"""HTTP client for GitHub's REST and GraphQL APIs: rate limits, retries and caching."""

from __future__ import annotations

import json
import logging
import time
from collections.abc import Callable, Mapping
from typing import Any

import httpx

from gh_ledger import __version__
from gh_ledger.cache import ResponseCache

API_URL = "https://api.github.com"
GRAPHQL_PATH = "/graphql"
SEARCH_INTERVAL = 2.1  # seconds between search calls keeps us under 30 per minute
MAX_SERVER_RETRIES = 3
SECONDARY_LIMIT_WAIT = 60.0
# SSO-protected orgs and deleted repos answer with these alongside usable data.
TOLERATED_GRAPHQL_ERRORS = frozenset({"NOT_FOUND", "FORBIDDEN"})

log = logging.getLogger(__name__)

Params = Mapping[str, str | int]
Waiter = Callable[[float, str], None]


class GitHubError(Exception):
    """A request failed in a way that retrying will not fix."""


class NotFoundError(GitHubError):
    """GitHub answered 404."""


class GraphQLError(GitHubError):
    """A GraphQL response carried errors that make its data unusable."""


class GitHubClient:
    def __init__(
        self,
        token: str,
        *,
        cache: ResponseCache | None = None,
        refresh: bool = False,
        transport: httpx.BaseTransport | None = None,
        sleep: Callable[[float], None] = time.sleep,
        clock: Callable[[], float] = time.time,
        on_wait: Waiter | None = None,
    ) -> None:
        self._http = httpx.Client(
            base_url=API_URL,
            transport=transport,
            timeout=60.0,
            headers={
                "Authorization": f"Bearer {token}",
                "Accept": "application/vnd.github+json",
                "X-GitHub-Api-Version": "2022-11-28",
                "User-Agent": f"gh-ledger/{__version__}",
            },
        )
        self._cache = cache
        self._refresh = refresh
        self._sleep = sleep
        self._clock = clock
        self._on_wait: Waiter = on_wait or (lambda seconds, _reason: sleep(seconds))
        self._last_search: float | None = None

    def close(self) -> None:
        self._http.close()

    def __enter__(self) -> GitHubClient:
        return self

    def __exit__(self, *_exc: object) -> None:
        self.close()

    def rest(
        self, path: str, params: Params | None = None, *, search: bool = False, cacheable: bool = True
    ) -> Any:
        return self._request("GET", path, params, None, search=search, cacheable=cacheable)

    def graphql(
        self,
        query: str,
        variables: Mapping[str, Any] | None = None,
        *,
        search: bool = False,
        cacheable: bool = True,
    ) -> dict[str, Any]:
        body = {"query": query, "variables": dict(variables or {})}
        response = self._request("POST", GRAPHQL_PATH, None, body, search=search, cacheable=cacheable)
        for error in response.get("errors") or []:
            log.warning("GitHub GraphQL: %s", error.get("message"))
        return response["data"]

    def _request(
        self,
        method: str,
        path: str,
        params: Params | None,
        body: dict[str, Any] | None,
        *,
        search: bool,
        cacheable: bool,
    ) -> Any:
        url = str(self._http.build_request(method, path, params=params).url)
        payload = json.dumps(body, sort_keys=True) if body is not None else ""
        key = ResponseCache.key(method, url, payload)
        cache = self._cache if cacheable else None
        if cache is not None and not self._refresh:
            hit = cache.get(key)
            if hit is not None:
                return hit
        result = self._send(method, path, params, body, search=search)
        if cache is not None:
            cache.put(key, result)
        return result

    def _send(
        self,
        method: str,
        path: str,
        params: Params | None,
        body: dict[str, Any] | None,
        *,
        search: bool,
    ) -> Any:
        server_failures = 0
        while True:
            if search:
                self._space_search()
            try:
                response = self._http.request(method, path, params=params, json=body)
            except httpx.TransportError as exc:
                failure = f"{type(exc).__name__}: {exc}"
            else:
                if response.status_code < 500:
                    wait = self._limit_wait(response, path)
                    if wait is not None:
                        self._on_wait(wait, "GitHub rate limit")
                        continue
                    return self._decode(response, path)
                failure = f"HTTP {response.status_code}"
            if server_failures >= MAX_SERVER_RETRIES:
                raise GitHubError(
                    f"{method} {path} failed after {MAX_SERVER_RETRIES} retries: {failure}"
                )
            self._sleep(2.0**server_failures)
            server_failures += 1

    def _limit_wait(self, response: httpx.Response, path: str) -> float | None:
        """Seconds to wait if this response is a rate limit, else None."""
        if response.status_code in (403, 429):
            retry_after = response.headers.get("Retry-After")
            if retry_after is not None:
                return float(retry_after)
            if response.headers.get("X-RateLimit-Remaining") == "0":
                return self._until_reset(response)
            if "secondary rate limit" in response.text.lower():
                return SECONDARY_LIMIT_WAIT
            return None
        if path == GRAPHQL_PATH and response.status_code == 200:
            errors = response.json().get("errors") or []
            if any(error.get("type") == "RATE_LIMITED" for error in errors):
                return self._until_reset(response)
        return None

    def _until_reset(self, response: httpx.Response) -> float:
        reset = float(response.headers.get("X-RateLimit-Reset", "0"))
        return max(reset - self._clock(), 0.0) + 1.0

    def _decode(self, response: httpx.Response, path: str) -> Any:
        if response.status_code == 404:
            raise NotFoundError(f"404 for {path}")
        if response.status_code >= 400:
            raise GitHubError(f"HTTP {response.status_code} for {path}: {response.text[:300]}")
        data = response.json()
        if path == GRAPHQL_PATH:
            errors = data.get("errors") or []
            fatal = [e for e in errors if e.get("type") not in TOLERATED_GRAPHQL_ERRORS]
            if data.get("data") is None or fatal:
                messages = "; ".join(str(e.get("message")) for e in (fatal or errors))
                raise GraphQLError(messages or "GraphQL response had no data")
        return data

    def _space_search(self) -> None:
        if self._last_search is not None:
            gap = self._clock() - self._last_search
            if gap < SEARCH_INTERVAL:
                self._sleep(SEARCH_INTERVAL - gap)
        self._last_search = self._clock()
```

```python
"""Date windows for GitHub search, bisected to stay under the 1,000-result cap."""

from __future__ import annotations

import logging
from collections.abc import Callable, Iterable, Iterator
from dataclasses import dataclass
from datetime import UTC, date, datetime, time, timedelta
from typing import Any

from gh_ledger.client import GitHubClient

SEARCH_CAP = 1000
SETTLE_AFTER = timedelta(days=30)
QUALIFIER_TIME = "%Y-%m-%dT%H:%M:%S+00:00"
ONE_SECOND = timedelta(seconds=1)

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class Window:
    """An inclusive UTC time range, at one-second resolution."""

    start: datetime
    end: datetime

    def qualifier(self) -> str:
        return f"{self.start.strftime(QUALIFIER_TIME)}..{self.end.strftime(QUALIFIER_TIME)}"

    def halves(self) -> tuple[Window, Window] | None:
        seconds = int((self.end - self.start).total_seconds())
        if seconds < 1:
            return None
        mid = self.start + timedelta(seconds=seconds // 2)
        return Window(self.start, mid), Window(mid + ONE_SECOND, self.end)

    def is_settled(self, now: datetime) -> bool:
        """True when the window ended long enough ago that its results won't change."""
        return self.end < now - SETTLE_AFTER


@dataclass(frozen=True)
class Page[T]:
    total: int
    items: list[T]
    cursor: str | None  # pass back to fetch the next page; None when done


type PageFetcher[T] = Callable[[Window, str | None], Page[T]]


@dataclass(frozen=True)
class SearchHit:
    node: dict[str, Any]
    settled: bool  # came from a window old enough to be served from cache


def _day_start(day: date) -> datetime:
    return datetime.combine(day, time.min, tzinfo=UTC)


def _day_end(day: date) -> datetime:
    return datetime.combine(day, time(23, 59, 59), tzinfo=UTC)


def month_windows(since: date, until: date) -> list[Window]:
    """Calendar-month windows covering [since, until], clipped at both ends."""
    windows: list[Window] = []
    current = since
    while current <= until:
        next_month = date(current.year + current.month // 12, current.month % 12 + 1, 1)
        last = min(next_month - timedelta(days=1), until)
        windows.append(Window(_day_start(current), _day_end(last)))
        current = next_month
    return windows


def year_spans(since: date, until: date) -> list[Window]:
    """Spans of at most 365 days: contributionsCollection rejects ranges over a year."""
    spans: list[Window] = []
    start, end = _day_start(since), _day_end(until)
    while start <= end:
        span_end = min(start + timedelta(days=365) - ONE_SECOND, end)
        spans.append(Window(start, span_end))
        start = span_end + ONE_SECOND
    return spans


def search_windowed[T](
    windows: Iterable[Window], fetch_page: PageFetcher[T], cap: int = SEARCH_CAP
) -> Iterator[T]:
    """Yield every result, bisecting any window whose total exceeds the cap."""
    for window in windows:
        yield from _search_window(window, fetch_page, cap)


def _search_window[T](window: Window, fetch_page: PageFetcher[T], cap: int) -> Iterator[T]:
    first = fetch_page(window, None)
    if first.total > cap:
        halves = window.halves()
        if halves is not None:
            for half in halves:
                yield from _search_window(half, fetch_page, cap)
            return
        log.warning("Search window %s has %d results; only %d are reachable", window, first.total, cap)
    yield from first.items
    cursor = first.cursor
    while cursor is not None:
        page = fetch_page(window, cursor)
        yield from page.items
        cursor = page.cursor


def graphql_search(
    client: GitHubClient, document: str, terms: str, field: str, now: datetime
) -> PageFetcher[SearchHit]:
    """Page through a GraphQL search on one date qualifier, e.g. `created:<window>`."""

    def fetch_page(window: Window, cursor: str | None) -> Page[SearchHit]:
        settled = window.is_settled(now)
        data = client.graphql(
            document,
            {"q": f"{terms} {field}:{window.qualifier()}", "after": cursor},
            search=True,
            cacheable=settled,
        )
        found = data["search"]
        info = found["pageInfo"]
        hits = [SearchHit(node, settled) for node in found["nodes"] if node and node.get("id")]
        next_cursor = info["endCursor"] if info["hasNextPage"] else None
        return Page(total=found["issueCount"], items=hits, cursor=next_cursor)

    return fetch_page
```

```python
"""A fake GitHub API for fetch tests, plus factories for its response shapes."""

import json
import re

import httpx

from gh_ledger.client import GitHubClient


class FakeGitHub:
    """Routes GraphQL requests by operation name and REST requests by path.

    GraphQL handlers receive the request body ({"query", "variables"}) and return `data`.
    REST handlers receive the httpx.Request and return JSON or an httpx.Response.
    """

    def __init__(self):
        self.graphql = {}
        self.rest = {}
        self.calls = []
        self.bodies = []

    def handle(self, request):
        if request.url.path == "/graphql":
            body = json.loads(request.content)
            name = re.search(r"query (\w+)", body["query"]).group(1)
            self.calls.append(name)
            self.bodies.append(body)
            return httpx.Response(200, json={"data": self.graphql[name](body)})
        self.calls.append(request.url.path)
        result = self.rest[request.url.path](request)
        return result if isinstance(result, httpx.Response) else httpx.Response(200, json=result)

    def client(self):
        return GitHubClient(
            "test-token", transport=httpx.MockTransport(self.handle), sleep=lambda _s: None
        )

    def variables(self, name):
        return [b["variables"] for b in self.bodies if f"query {name}" in b["query"]]


def noop(_count):
    return None


def repo(name="octo/app", *, private=False, fork=False):
    return {"nameWithOwner": name, "isPrivate": private, "isFork": fork}


def connection(nodes, end_cursor=None):
    return {
        "pageInfo": {"hasNextPage": end_cursor is not None, "endCursor": end_cursor},
        "nodes": list(nodes),
    }


def search_result(nodes, *, total=None, end_cursor=None):
    return {
        "search": {
            "issueCount": len(nodes) if total is None else total,
            **connection(nodes, end_cursor),
        }
    }


def pr_node(
    node_id="PR_1",
    *,
    number=1,
    state="MERGED",
    created="2024-01-10T10:00:00Z",
    merged="2024-01-11T10:00:00Z",
    files=(("src/app.py", 10, 2),),
    messages=("feat: add app",),
    body="Adds the app.",
    changed_files=None,
    files_cursor=None,
    commits_cursor=None,
    repository=None,
):
    file_nodes = [
        {"path": p, "additions": a, "deletions": d, "changeType": "MODIFIED"} for p, a, d in files
    ]
    return {
        "id": node_id,
        "number": number,
        "url": f"https://github.com/octo/app/pull/{number}",
        "title": f"PR {number}",
        "state": state,
        "body": body,
        "createdAt": created,
        "mergedAt": merged if state == "MERGED" else None,
        "closedAt": merged if state in ("MERGED", "CLOSED") else None,
        "additions": sum(a for _, a, _ in files),
        "deletions": sum(d for _, _, d in files),
        "changedFiles": len(files) if changed_files is None else changed_files,
        "repository": repository or repo(),
        "files": connection(file_nodes, files_cursor),
        "commits": connection([{"commit": {"message": m}} for m in messages], commits_cursor),
    }
```

```python
"""Trailer parsing, path exclusion and AI-assistance markers."""

from __future__ import annotations

import re
from collections.abc import Iterable

_CO_AUTHOR = re.compile(r"^\s*co-authored-by:\s*(.+?)\s*$", re.IGNORECASE | re.MULTILINE)


def parse_co_authors(messages: Iterable[str]) -> tuple[str, ...]:
    """Union of `Co-authored-by` trailer values, first spelling wins, order kept."""
    seen: dict[str, str] = {}
    for message in messages:
        for match in _CO_AUTHOR.finditer(message):
            entry = match.group(1)
            seen.setdefault(entry.lower(), entry)
    return tuple(seen.values())
```

```python
"""Helpers shared by the fetch modules."""

from __future__ import annotations

from collections.abc import Callable
from datetime import UTC, datetime
from typing import Any

from gh_ledger.client import GitHubClient
from gh_ledger.model import RepoRow

GH_TIME = "%Y-%m-%dT%H:%M:%SZ"
EMPTY_CONNECTION: dict[str, Any] = {"pageInfo": {"hasNextPage": False, "endCursor": None}, "nodes": []}

Tick = Callable[[int], None]


def to_utc_iso(value: str) -> str:
    """Normalise a GitHub timestamp with any offset to `YYYY-MM-DDTHH:MM:SSZ`."""
    return datetime.fromisoformat(value).astimezone(UTC).strftime(GH_TIME)


def optional_utc_iso(value: str | None) -> str | None:
    return to_utc_iso(value) if value else None


def repo_row(repository: dict[str, Any]) -> RepoRow:
    """Build a RepoRow from GraphQL `repository { nameWithOwner isPrivate isFork }`."""
    return RepoRow(
        repo=repository["nameWithOwner"],
        is_private=bool(repository["isPrivate"]),
        is_fork=bool(repository["isFork"]),
    )


def login_of(actor: dict[str, Any] | None) -> str:
    """Login of a GraphQL actor; empty for deleted (ghost) accounts."""
    return str(actor["login"]) if actor else ""


def connection_or_empty(value: dict[str, Any] | None) -> dict[str, Any]:
    """GitHub returns null instead of a connection for some very large PRs."""
    return value if value is not None else EMPTY_CONNECTION


def drain_connection(
    client: GitHubClient,
    query: str,
    node_id: str,
    field: str,
    page_info: dict[str, Any],
    *,
    cacheable: bool,
) -> list[dict[str, Any]]:
    """Fetch the remaining pages of `node(id).<field>` after the first page."""
    nodes: list[dict[str, Any]] = []
    while page_info["hasNextPage"]:
        variables = {"id": node_id, "after": page_info["endCursor"]}
        conn = client.graphql(query, variables, cacheable=cacheable)["node"][field]
        nodes.extend(conn["nodes"])
        page_info = conn["pageInfo"]
    return nodes
```

```python
"""Authored pull requests, with their file lists and commit messages."""

from __future__ import annotations

from datetime import date, datetime
from typing import Any

from gh_ledger.client import GitHubClient
from gh_ledger.fetch.common import (
    Tick,
    connection_or_empty,
    drain_connection,
    optional_utc_iso,
    repo_row,
    to_utc_iso,
)
from gh_ledger.fetch.search import SearchHit, graphql_search, month_windows, search_windowed
from gh_ledger.filters import parse_co_authors
from gh_ledger.model import FetchResult, FileChangeRow, PrRow

PR_FIELDS = """
fragment PrFields on PullRequest {
  id number url title state body createdAt mergedAt closedAt
  additions deletions changedFiles
  repository { nameWithOwner isPrivate isFork }
  files(first: 100) {
    pageInfo { hasNextPage endCursor }
    nodes { path additions deletions changeType }
  }
  commits(first: 100) {
    pageInfo { hasNextPage endCursor }
    nodes { commit { message } }
  }
}
"""

SEARCH_QUERY = (
    """
query PrSearch($q: String!, $after: String) {
  search(type: ISSUE, query: $q, first: 50, after: $after) {
    issueCount
    pageInfo { hasNextPage endCursor }
    nodes { ...PrFields }
  }
}
"""
    + PR_FIELDS
)

NODE_QUERY = "query PrNode($id: ID!) { node(id: $id) { ...PrFields } }\n" + PR_FIELDS

FILES_QUERY = """
query PrFiles($id: ID!, $after: String) {
  node(id: $id) { ... on PullRequest {
    files(first: 100, after: $after) {
      pageInfo { hasNextPage endCursor }
      nodes { path additions deletions changeType }
    }
  } }
}
"""

COMMITS_QUERY = """
query PrCommits($id: ID!, $after: String) {
  node(id: $id) { ... on PullRequest {
    commits(first: 100, after: $after) {
      pageInfo { hasNextPage endCursor }
      nodes { commit { message } }
    }
  } }
}
"""


def fetch_prs(
    client: GitHubClient,
    user: str,
    since: date,
    until: date,
    *,
    public_only: bool,
    now: datetime,
    tick: Tick,
) -> FetchResult:
    """PRs created or merged in [since, until]: one search on each date, merged by ID."""
    terms = f"is:pr author:{user}" + (" is:public" if public_only else "")
    windows = month_windows(since, until)
    found: dict[str, SearchHit] = {}
    for field in ("created", "merged"):
        pages = graphql_search(client, SEARCH_QUERY, terms, field, now)
        for hit in search_windowed(windows, pages):
            previous = found.get(hit.node["id"])
            if previous is None or not hit.settled:  # a fresh copy beats a cached one
                found[hit.node["id"]] = hit
            tick(1)
    result = FetchResult()
    for hit in found.values():
        node = hit.node
        if hit.settled and node["state"] == "OPEN":
            # Cached search pages freeze an open PR; its details are re-read every run.
            node = client.graphql(NODE_QUERY, {"id": node["id"]}, cacheable=False)["node"]
        _add_pr(client, node, result)
    return result


def _add_pr(client: GitHubClient, node: dict[str, Any], result: FetchResult) -> None:
    cacheable = node["state"] != "OPEN"
    files_conn = connection_or_empty(node["files"])
    commits_conn = connection_or_empty(node["commits"])
    files = [
        *files_conn["nodes"],
        *drain_connection(
            client, FILES_QUERY, node["id"], "files", files_conn["pageInfo"], cacheable=cacheable
        ),
    ]
    commits = [
        *commits_conn["nodes"],
        *drain_connection(
            client, COMMITS_QUERY, node["id"], "commits", commits_conn["pageInfo"], cacheable=cacheable
        ),
    ]
    messages = [str(c["commit"]["message"]) for c in commits]
    created = to_utc_iso(node["createdAt"])
    merged = optional_utc_iso(node["mergedAt"])
    repo = repo_row(node["repository"])
    result.repos.append(repo)
    result.prs.append(
        PrRow(
            id=node["id"],
            repo=repo.repo,
            number=node["number"],
            url=node["url"],
            title=node["title"],
            state=str(node["state"]).lower(),
            created_at=created,
            merged_at=merged,
            closed_at=optional_utc_iso(node["closedAt"]),
            additions=node["additions"],
            deletions=node["deletions"],
            changed_files=node["changedFiles"],
            files_truncated=len(files) < node["changedFiles"],
            text="\n\n".join([node["body"] or "", *messages]).strip(),
            co_authors=parse_co_authors(messages),
        )
    )
    file_date = merged or created
    result.file_changes.extend(
        FileChangeRow(
            source="pr",
            source_id=node["id"],
            repo=repo.repo,
            path=f["path"],
            additions=f["additions"],
            deletions=f["deletions"],
            change_type=str(f["changeType"]).lower(),
            date=file_date,
        )
        for f in files
    )
```

```python
"""Issues the user opened."""

from __future__ import annotations

from datetime import date, datetime

from gh_ledger.client import GitHubClient
from gh_ledger.fetch.common import Tick, optional_utc_iso, repo_row, to_utc_iso
from gh_ledger.fetch.search import graphql_search, month_windows, search_windowed
from gh_ledger.model import FetchResult, IssueRow

SEARCH_QUERY = """
query IssueSearch($q: String!, $after: String) {
  search(type: ISSUE, query: $q, first: 100, after: $after) {
    issueCount
    pageInfo { hasNextPage endCursor }
    nodes {
      ... on Issue {
        id number url title state body createdAt closedAt
        repository { nameWithOwner isPrivate isFork }
      }
    }
  }
}
"""


def fetch_issues(
    client: GitHubClient,
    user: str,
    since: date,
    until: date,
    *,
    public_only: bool,
    now: datetime,
    tick: Tick,
) -> FetchResult:
    terms = f"is:issue author:{user}" + (" is:public" if public_only else "")
    pages = graphql_search(client, SEARCH_QUERY, terms, "created", now)
    result = FetchResult()
    for hit in search_windowed(month_windows(since, until), pages):
        node = hit.node
        repo = repo_row(node["repository"])
        result.repos.append(repo)
        result.issues.append(
            IssueRow(
                id=node["id"],
                repo=repo.repo,
                number=node["number"],
                url=node["url"],
                title=node["title"],
                state=str(node["state"]).lower(),
                created_at=to_utc_iso(node["createdAt"]),
                closed_at=optional_utc_iso(node["closedAt"]),
                text=node["body"] or "",
            )
        )
        tick(1)
    return result
```

```python
"""Submitted reviews and their inline comments, from contributionsCollection."""

from __future__ import annotations

from datetime import date, datetime
from typing import Any

from gh_ledger.client import GitHubClient
from gh_ledger.fetch.common import GH_TIME, Tick, drain_connection, login_of, repo_row, to_utc_iso

from gh_ledger.model import CommentRow, FetchResult, ReviewRow

QUERY = """
query ReviewContributions($login: String!, $from: DateTime!, $to: DateTime!, $after: String) {
  user(login: $login) {
    contributionsCollection(from: $from, to: $to) {
      restrictedContributionsCount
      pullRequestReviewContributions(first: 100, after: $after) {
        pageInfo { hasNextPage endCursor }
        nodes {
          pullRequestReview {
            id state body submittedAt
            comments(first: 100) {
              pageInfo { hasNextPage endCursor }
              nodes { id body createdAt url }
            }
          }
          pullRequest { number url author { login } }
          repository { nameWithOwner isPrivate isFork }
        }
      }
    }
  }
}
"""

COMMENTS_QUERY = """
query ReviewComments($id: ID!, $after: String) {
  node(id: $id) { ... on PullRequestReview {
    comments(first: 100, after: $after) {
      pageInfo { hasNextPage endCursor }
      nodes { id body createdAt url }
    }
  } }
}
"""


def fetch_reviews(
    client: GitHubClient, user: str, since: date, until: date, *, now: datetime, tick: Tick
) -> FetchResult:
    result = FetchResult()
    for span in year_spans(since, until):
        cacheable = span.is_settled(now)
        cursor: str | None = None
        while True:
            variables = {
                "login": user,
                "from": span.start.strftime(GH_TIME),
                "to": span.end.strftime(GH_TIME),
                "after": cursor,
            }
            collection = client.graphql(QUERY, variables, cacheable=cacheable)["user"][
                "contributionsCollection"
            ]
            if cursor is None:
                result.restricted_contributions += collection["restrictedContributionsCount"]
            conn = collection["pullRequestReviewContributions"]
            for node in conn["nodes"]:
                _add_review(client, node, result, cacheable=cacheable)
                tick(1)
            if not conn["pageInfo"]["hasNextPage"]:
                break
            cursor = conn["pageInfo"]["endCursor"]
    return result


def _add_review(
    client: GitHubClient, node: dict[str, Any], result: FetchResult, *, cacheable: bool
) -> None:
    review = node["pullRequestReview"]
    pr = node["pullRequest"]
    repo = repo_row(node["repository"])
    author = login_of(pr["author"])
    result.repos.append(repo)
    result.reviews.append(
        ReviewRow(
            id=review["id"],
            repo=repo.repo,
            pr_number=pr["number"],
            pr_url=pr["url"],
            pr_author=author,
            state=str(review["state"]).lower(),
            submitted_at=to_utc_iso(review["submittedAt"]),
            text=review["body"] or "",
        )
    )
    comments = [
        *review["comments"]["nodes"],
        *drain_connection(
            client,
            COMMENTS_QUERY,
            review["id"],
            "comments",
            review["comments"]["pageInfo"],
            cacheable=cacheable,
        ),
    ]
    result.comments.extend(
        CommentRow(
            id=c["id"],
            repo=repo.repo,
            kind="review_inline",
            parent_number=pr["number"],
            parent_url=pr["url"],
            parent_author=author,
            created_at=to_utc_iso(c["createdAt"]),
            text=c["body"] or "",
        )
        for c in comments
    )
```

```python
"""Conversation comments on issues and PRs, from user.issueComments."""

from __future__ import annotations

from datetime import UTC, date, datetime, time

from gh_ledger.client import GitHubClient
from gh_ledger.fetch.common import Tick, login_of, repo_row, to_utc_iso
from gh_ledger.model import CommentRow, FetchResult

QUERY = """
query IssueComments($login: String!, $after: String) {
  user(login: $login) {
    issueComments(first: 100, after: $after, orderBy: {field: UPDATED_AT, direction: DESC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        id body createdAt updatedAt
        issue { number url author { login } }
        pullRequest { number url author { login } }
        repository { nameWithOwner isPrivate isFork }
      }
    }
  }
}
"""


def fetch_comments(
    client: GitHubClient, user: str, since: date, until: date, *, tick: Tick
) -> FetchResult:
    """Read newest-updated first until a page ends before `since`.

    The stream shifts as new comments arrive, so pages are never cached.
    """
    start = datetime.combine(since, time.min, tzinfo=UTC)
    end = datetime.combine(until, time.max, tzinfo=UTC)
    result = FetchResult()
    cursor: str | None = None
    while True:
        variables = {"login": user, "after": cursor}
        conn = client.graphql(QUERY, variables, cacheable=False)["user"]["issueComments"]
        nodes = conn["nodes"]
        for node in nodes:
            tick(1)
            if not start <= datetime.fromisoformat(node["createdAt"]) <= end:
                continue
            parent = node["pullRequest"] or node["issue"]
            repo = repo_row(node["repository"])
            result.repos.append(repo)
            result.comments.append(
                CommentRow(
                    id=node["id"],
                    repo=repo.repo,
                    kind="pr_conversation" if node["pullRequest"] else "issue",
                    parent_number=parent["number"],
                    parent_url=parent["url"],
                    parent_author=login_of(parent["author"]),
                    created_at=to_utc_iso(node["createdAt"]),
                    text=node["body"] or "",
                )
            )
        past_since = bool(nodes) and datetime.fromisoformat(nodes[-1]["updatedAt"]) < start
        if past_since or not conn["pageInfo"]["hasNextPage"]:
            return result
        cursor = conn["pageInfo"]["endCursor"]
```

```python
def commit_item(sha, date="2024-01-12T10:00:00.000+00:00", *, repo_name="octo/app", private=False, message="fix: thing"):
    return {
        "sha": sha,
        "commit": {"author": {"date": date}, "message": message},
        "repository": {"full_name": repo_name, "private": private, "fork": False},
    }


def commit_detail(sha, files, *, stats=None):
    """files: (filename, additions, deletions) tuples. stats defaults to their sums."""
    additions = sum(a for _, a, _ in files)
    deletions = sum(d for _, _, d in files)
    stats = stats or {"additions": additions, "deletions": deletions}
    return {
        "sha": sha,
        "stats": {**stats, "total": stats["additions"] + stats["deletions"]},
        "files": [
            {"filename": f, "additions": a, "deletions": d, "status": "modified"} for f, a, d in files
        ],
    }


def associations(attached=(), missing_repos=()):
    """Answer a CommitAssociations query: SHAs in `attached` belong to a PR."""

    def handle(body):
        data = {}
        pattern = r'(c\d+): repository\(owner: "([^"]+)", name: "([^"]+)"\) \{ object\(oid: "(\w+)"\)'
        for alias, owner, name, sha in re.findall(pattern, body["query"]):
            if f"{owner}/{name}" in missing_repos:
                data[alias] = None
            else:
                count = 1 if sha in attached else 0
                data[alias] = {"object": {"associatedPullRequests": {"totalCount": count}}}
        return data

    return handle
```

```python
) -> FetchResult:
    visibility = " is:public" if public_only else ""
    authors = [f"author:{user}", *(f"author-email:{email}" for email in author_emails)]
    windows = month_windows(since, until)
    candidates: dict[str, dict[str, Any]] = {}
    for author in authors:
        for item in search_windowed(windows, _search_pages(client, author + visibility, now)):
            candidates.setdefault(item["sha"], item)
            tick(1)
    items = sorted(candidates.values(), key=lambda item: _authored(item))
    attached, missing = _associations(client, items, now)
    result = FetchResult(dropped_pr_commits=len(attached))
    skipped = set(missing)
    for item in items:
        full_name = item["repository"]["full_name"]
        if item["sha"] in attached or full_name in skipped:
            continue
        try:
            detail, files = _detail(client, full_name, item["sha"])
        except NotFoundError:
            skipped.add(full_name)
            continue
        _add_commit(item, detail, files, result)
    result.skipped_repos = sorted(skipped)
    return result


def _authored(item: dict[str, Any]) -> datetime:
    return datetime.fromisoformat(item["commit"]["author"]["date"])


def _search_pages(client: GitHubClient, terms: str, now: datetime) -> PageFetcher[dict[str, Any]]:
    def fetch_page(window: Window, cursor: str | None) -> Page[dict[str, Any]]:
        page = int(cursor or "1")
        data = client.rest(
            SEARCH_PATH,
            {
                "q": f"{terms} author-date:{window.qualifier()}",
                "sort": "author-date",
                "order": "asc",
                "per_page": PER_PAGE,
                "page": page,
            },
            search=True,
            cacheable=window.is_settled(now),
        )
        total = int(data["total_count"])
        more = page * PER_PAGE < min(total, SEARCH_CAP)
        return Page(total=total, items=list(data["items"]), cursor=str(page + 1) if more else None)

    return fetch_page


def _associations(
    client: GitHubClient, items: list[dict[str, Any]], now: datetime
) -> tuple[set[str], set[str]]:
    """SHAs attached to a PR, and repos the association query could not see."""
    attached: set[str] = set()
    missing: set[str] = set()
    for start in range(0, len(items), ASSOCIATION_BATCH):
        batch = items[start : start + ASSOCIATION_BATCH]
        parts: list[str] = []
        for i, item in enumerate(batch):
            owner, name = str(item["repository"]["full_name"]).split("/", 1)
            parts.append(
                ASSOCIATION.format(i=i, owner=json.dumps(owner), name=json.dumps(name), sha=item["sha"])
            )
        settled = all(_authored(item) < now - SETTLE_AFTER for item in batch)
        query = "query CommitAssociations {\n" + "\n".join(parts) + "\n}"
        data = client.graphql(query, cacheable=settled)
        for i, item in enumerate(batch):
            repository = data.get(f"c{i}")
            if repository is None:
                missing.add(item["repository"]["full_name"])
                continue
            commit = repository.get("object")
            if commit and commit["associatedPullRequests"]["totalCount"] > 0:
                attached.add(item["sha"])
    return attached, missing


def _detail(
    client: GitHubClient, full_name: str, sha: str
) -> tuple[dict[str, Any], list[dict[str, Any]]]:
    first: dict[str, Any] | None = None
    files: list[dict[str, Any]] = []
    for page in range(1, MAX_FILE_PAGES + 1):
        data = client.rest(f"/repos/{full_name}/commits/{sha}", {"per_page": PER_PAGE, "page": page})
        first = first or data
        page_files = list(data.get("files") or [])
        files.extend(page_files)
        if len(page_files) < PER_PAGE:
            break
    assert first is not None
    return first, files


def _add_commit(
    item: dict[str, Any], detail: dict[str, Any], files: list[dict[str, Any]], result: FetchResult
) -> None:
    repository = item["repository"]
    repo = RepoRow(
        repo=repository["full_name"],
        is_private=bool(repository["private"]),
        is_fork=bool(repository["fork"]),
    )
    authored = to_utc_iso(item["commit"]["author"]["date"])
    message = str(item["commit"]["message"])
    stats = detail["stats"]
    listed = (sum(f["additions"] for f in files), sum(f["deletions"] for f in files))
    result.repos.append(repo)
    result.commits.append(
        CommitRow(
            sha=item["sha"],
            repo=repo.repo,
            authored_at=authored,
            additions=stats["additions"],
            deletions=stats["deletions"],
            files_truncated=listed != (stats["additions"], stats["deletions"]),
            text=message,
            co_authors=parse_co_authors([message]),
        )
    )
    result.file_changes.extend(
        FileChangeRow(
            source="commit",
            source_id=item["sha"],
            repo=repo.repo,
            path=f["filename"],
            additions=f["additions"],
            deletions=f["deletions"],
            change_type=str(f["status"]),
            date=authored,
        )
        for f in files
    )
```

```python
"""Fetch a user's activity from GitHub into the normalised tables."""

from __future__ import annotations

import dataclasses
from collections.abc import Callable
from contextlib import AbstractContextManager
from dataclasses import dataclass
from datetime import date, datetime
from pathlib import Path

from gh_ledger import __version__
from gh_ledger.client import GitHubClient
from gh_ledger.fetch.comments import fetch_comments
from gh_ledger.fetch.commits import fetch_commits
from gh_ledger.fetch.common import GH_TIME, Tick
from gh_ledger.fetch.issues import fetch_issues
from gh_ledger.fetch.prs import fetch_prs
from gh_ledger.fetch.reviews import fetch_reviews
from gh_ledger.model import FetchResult, Manifest
from gh_ledger.store import read_manifest, write_manifest, write_tables

Stage = Callable[[str], AbstractContextManager[Tick]]

USER_QUERY = "query UserCheck($login: String!) { user(login: $login) { login } }"


class FetchError(Exception):
    """The fetch cannot proceed with these options."""


@dataclass(frozen=True)
class FetchOptions:
    user: str
    since: date
    until: date
    visibility: str  # public | all
    author_emails: tuple[str, ...] = ()


def run_fetch(
    client: GitHubClient, options: FetchOptions, data_dir: Path, *, now: datetime, stage: Stage
) -> Manifest:
    existing = read_manifest(data_dir)
    check_compatible(existing, options, data_dir)
    user = _canonical_login(client, options.user)
    public_only = options.visibility == "public"
    since, until = options.since, options.until
    result = FetchResult()
    with stage("Pull requests") as tick:
        result.extend(fetch_prs(client, user, since, until, public_only=public_only, now=now, tick=tick))
    with stage("Issues") as tick:
        result.extend(fetch_issues(client, user, since, until, public_only=public_only, now=now, tick=tick))
    with stage("Reviews") as tick:
        result.extend(fetch_reviews(client, user, since, until, now=now, tick=tick))
    with stage("Comments") as tick:
        result.extend(fetch_comments(client, user, since, until, tick=tick))
    with stage("Direct commits") as tick:
        result.extend(
            fetch_commits(
                client,
                user,
                since,
                until,
                author_emails=options.author_emails,
                public_only=public_only,
                now=now,
                tick=tick,
            )
        )
    if public_only:
        result = drop_private(result)
    result.repos = list({row.repo: row for row in result.repos}.values())
    write_tables(data_dir, result)
    manifest = _merge_manifest(existing, options, user, result, now)
    write_manifest(data_dir, manifest)
    return manifest


def check_compatible(existing: Manifest | None, options: FetchOptions, data_dir: Path) -> None:
    """Refuse to mix users or visibilities in one data directory."""
    if existing is None:
        return
    if existing.user.lower() != options.user.lower():
        raise FetchError(
            f"{data_dir} holds data for {existing.user}. Use a different --data directory for {options.user}."
        )
    if existing.visibility != options.visibility:
        raise FetchError(
            f"{data_dir} was fetched with --visibility {existing.visibility}. "
            "Re-run with that, or use a different --data directory."
        )


def drop_private(result: FetchResult) -> FetchResult:
    """Remove every row belonging to a private repo."""
    private = {row.repo for row in result.repos if row.is_private}
    return dataclasses.replace(
        result,
        repos=[row for row in result.repos if not row.is_private],
        prs=[row for row in result.prs if row.repo not in private],
        issues=[row for row in result.issues if row.repo not in private],
        reviews=[row for row in result.reviews if row.repo not in private],
        comments=[row for row in result.comments if row.repo not in private],
        commits=[row for row in result.commits if row.repo not in private],
        file_changes=[row for row in result.file_changes if row.repo not in private],
    )


def _canonical_login(client: GitHubClient, login: str) -> str:
    user = client.graphql(USER_QUERY, {"login": login}, cacheable=False)["user"]
    if user is None:
        raise FetchError(f"No GitHub user {login!r}")
    return str(user["login"])


def _merge_manifest(
    existing: Manifest | None, options: FetchOptions, user: str, result: FetchResult, now: datetime
) -> Manifest:
    since, until = options.since.isoformat(), options.until.isoformat()
    emails = set(options.author_emails)
    skipped = set(result.skipped_repos)
    if existing is not None:
        since, until = min(since, existing.since), max(until, existing.until)
        emails |= set(existing.author_emails)
        skipped |= set(existing.skipped_repos)
    return Manifest(
        user=user,
        since=since,
        until=until,
        visibility=options.visibility,
        fetched_at=now.strftime(GH_TIME),
        tool_version=__version__,
        author_emails=sorted(emails),
        dropped_pr_commits=result.dropped_pr_commits,
        skipped_repos=sorted(skipped),
        restricted_contributions=result.restricted_contributions,
    )
```

```python
"""Command-line interface: fetch, summary and report."""

from __future__ import annotations

import math
import time
from collections.abc import Iterator
from contextlib import contextmanager
from datetime import UTC, datetime
from enum import StrEnum
from pathlib import Path
from typing import Annotated, NoReturn

import typer
from rich.console import Console
from rich.markup import escape
from rich.progress import Progress, SpinnerColumn, TextColumn, TimeElapsedColumn

from gh_ledger.auth import AuthError, get_token
from gh_ledger.cache import ResponseCache
from gh_ledger.client import GitHubClient, GitHubError, Waiter
from gh_ledger.fetch import FetchError, FetchOptions, Stage, run_fetch
from gh_ledger.fetch.common import Tick

app = typer.Typer(
    no_args_is_help=True,
    add_completion=False,
    help="Measure one GitHub user's activity over time.",
)
console = Console()
# soft_wrap: long paths must not split messages mid-phrase.
err_console = Console(stderr=True, soft_wrap=True)


class Visibility(StrEnum):
    PUBLIC = "public"
    ALL = "all"


def fail(message: object) -> NoReturn:
    # escape(): messages contain brackets ("[filters]", "gh-ledger[images]") that rich reads as markup.
    err_console.print(f"[red]Error:[/] {escape(str(message))}")
    raise typer.Exit(1)


def make_client(data: Path, *, refresh: bool, on_wait: Waiter) -> GitHubClient:
    return GitHubClient(
        get_token(), cache=ResponseCache(data / "cache"), refresh=refresh, on_wait=on_wait
    )


def _stage_runner(progress: Progress) -> Stage:
    @contextmanager
    def stage(name: str) -> Iterator[Tick]:
        task = progress.add_task(name, total=None)

        def tick(count: int) -> None:
            progress.advance(task, count)

        yield tick
        progress.update(task, description=f"{name} [green]done[/]")
        progress.stop_task(task)

    return stage


def _waiter(progress: Progress) -> Waiter:
    def wait(seconds: float, reason: str) -> None:
        remaining = math.ceil(seconds)
        task = progress.add_task(f"{reason}: resuming in {remaining}s", total=None)
        while remaining > 0:
            time.sleep(1)
            remaining -= 1
            progress.update(task, description=f"{reason}: resuming in {remaining}s")
        progress.remove_task(task)

    return wait


@app.command()
def fetch(
    user: Annotated[str, typer.Option(help="GitHub login to measure.")],
    since: Annotated[datetime, typer.Option(formats=["%Y-%m-%d"], help="First day (UTC).")],
    data: Annotated[Path, typer.Option(help="Directory for tables, manifest and cache.")],
    until: Annotated[
        datetime | None, typer.Option(formats=["%Y-%m-%d"], help="Last day (UTC). Default: today.")
    ] = None,
    visibility: Annotated[
        Visibility, typer.Option(help="Public repos only, or everything the token can see.")
    ] = Visibility.PUBLIC,
    author_email: Annotated[
        list[str] | None,
        typer.Option(help="Commit email not linked to the account. Repeatable."),
    ] = None,
    refresh: Annotated[bool, typer.Option(help="Ignore the cache and re-fetch everything.")] = False,
) -> None:
    """Fetch activity from GitHub into DATA."""
    now = datetime.now(UTC)
    start = since.date()
    end = until.date() if until else now.date()
    if start > end:
        fail(f"--since {start} is after --until {end}")
    options = FetchOptions(
        user=user,
        since=start,
        until=end,
        visibility=visibility.value,
        author_emails=tuple(author_email or ()),
    )
    columns = (
        SpinnerColumn(),
        TextColumn("{task.description}"),
        TextColumn("{task.completed:.0f} items"),
        TimeElapsedColumn(),
    )
    try:
        with (
            Progress(*columns, console=err_console) as progress,
            make_client(data, refresh=refresh, on_wait=_waiter(progress)) as client,
        ):
            manifest = run_fetch(client, options, data, now=now, stage=_stage_runner(progress))
    except (AuthError, FetchError, GitHubError) as exc:
        fail(exc)
    err_console.print(f"Fetched {manifest.user} {manifest.since} to {manifest.until} into {data}")
    if manifest.dropped_pr_commits:
        err_console.print(f"Dropped {manifest.dropped_pr_commits} commits already counted via PRs.")
    if manifest.skipped_repos:
        err_console.print(f"[yellow]Skipped repos (not found):[/] {escape(', '.join(manifest.skipped_repos))}")
    if manifest.restricted_contributions:
        err_console.print(
            f"[yellow]{manifest.restricted_contributions} private contributions are hidden from this token.[/]"
        )
```

```python
def _glob_to_regex(pattern: str) -> str:
    parts: list[str] = []
    i = 0
    while i < len(pattern):
        if pattern.startswith("**/", i):
            parts.append("(?:.*/)?")
            i += 3
        elif pattern.startswith("**", i):
            parts.append(".*")
            i += 2
        elif pattern[i] == "*":
            parts.append("[^/]*")
            i += 1
        elif pattern[i] == "?":
            parts.append("[^/]")
            i += 1
        else:
            parts.append(re.escape(pattern[i]))
            i += 1
    return "".join(parts)


def _compile(globs: list[str]) -> re.Pattern[str] | None:
    if not globs:
        return None
    return re.compile("|".join(f"(?:{_glob_to_regex(glob)})" for glob in globs))


class PathFilter:
    """Decides whether a changed file is left out of filtered line counts.

    Patterns follow a subset of .gitignore:
    - `name/` excludes any path with a directory called `name`, at any depth.
    - A pattern without `/` matches the file name at any depth (`*.json`, `uv.lock`).
    - Any other pattern matches the whole path from the repo root (`fixtures/**`).
      `*` stays within one directory; `**` crosses directories.
    """

    def __init__(self, patterns: Iterable[str]) -> None:
        dirs: set[str] = set()
        names: list[str] = []
        paths: list[str] = []
        for raw in patterns:
            pattern = raw.lstrip("/")
            if pattern.endswith("/") and "/" not in pattern[:-1]:
                dirs.add(pattern[:-1])
            elif pattern.endswith("/"):
                paths.append(pattern + "**")
            elif "/" in pattern:
                paths.append(pattern)
            else:
                names.append(pattern)
        self._dirs = frozenset(dirs)
        self._names = _compile(names)
        self._paths = _compile(paths)

    def excluded(self, path: str) -> bool:
        *parents, name = path.split("/")
        if any(part in self._dirs for part in parents):
            return True
        if self._names is not None and self._names.fullmatch(name):
            return True
        return self._paths is not None and self._paths.fullmatch(path) is not None


class AiMatcher:
    """An item is AI-assisted if any pattern matches its text or a co-author trailer."""

    def __init__(self, patterns: Iterable[str]) -> None:
        self._patterns = [re.compile(pattern) for pattern in patterns]

    def matches(self, text: str, co_authors: Iterable[str] = ()) -> bool:
        candidates = [text, *(f"Co-Authored-By: {entry}" for entry in co_authors)]
        return any(p.search(c) for p in self._patterns for c in candidates)
```

```python
"""Load `ledger.toml`. Every key is optional and falls back to a built-in default."""

from __future__ import annotations

import re
import tomllib
from dataclasses import dataclass, field
from datetime import date, datetime
from pathlib import Path
from typing import Any, cast

from gh_ledger.filters import DEFAULT_AI_PATTERNS, DEFAULT_EXCLUDES

PERIODS = ("week", "month", "quarter")
CHART_NAMES = ("activity", "lines", "review_mix", "ai_share", "repos", "compare")
MAX_TOP_REPOS = 8  # one categorical colour each; the rest fold into "other"

Table = dict[str, object]


class ConfigError(Exception):
    """ledger.toml is unreadable or holds an invalid value."""


@dataclass(frozen=True)
class FiltersConfig:
    exclude: tuple[str, ...] = DEFAULT_EXCLUDES
    per_file_cap: int | None = 1000
    count_unmerged_pr_lines: bool = False


@dataclass(frozen=True)
class AiConfig:
    patterns: tuple[str, ...] = DEFAULT_AI_PATTERNS


@dataclass(frozen=True)
class ReportConfig:
    period: str = "month"
    title: str = "GitHub activity"
    top_repos: int = 8
    compare_at: date | None = None
    charts: tuple[str, ...] = CHART_NAMES
    image_size: tuple[int, int] = (1200, 600)


@dataclass(frozen=True)
class Config:
    filters: FiltersConfig = field(default_factory=FiltersConfig)
    ai: AiConfig = field(default_factory=AiConfig)
    report: ReportConfig = field(default_factory=ReportConfig)


def load_config(path: Path | None) -> Config:
    if path is None:
        return Config()
    try:
        raw: dict[str, Any] = tomllib.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError:
        raise ConfigError(f"Config file not found: {path}") from None
    except tomllib.TOMLDecodeError as exc:
        raise ConfigError(f"{path}: {exc}") from None
    try:
        _check_keys(raw, {"filters", "ai", "report"}, "the top level")
        return Config(
            filters=_filters(_table(raw, "filters")),
            ai=_ai(_table(raw, "ai")),
            report=_report(_table(raw, "report")),
        )
    except ConfigError as exc:
        raise ConfigError(f"{path}: {exc}") from None


def _table(raw: dict[str, Any], name: str) -> Table:
    value: object = raw.get(name, {})
    if not isinstance(value, dict):
        raise ConfigError(f"[{name}] must be a table")
    return cast(Table, value)


def _check_keys(table: dict[str, Any] | Table, allowed: set[str], where: str) -> None:
    unknown = sorted(set(table) - allowed)
    if unknown:
        raise ConfigError(f"unknown key {', '.join(unknown)} in {where}")


def _strings(value: object, key: str) -> tuple[str, ...]:
    if not isinstance(value, list):
        raise ConfigError(f"{key} must be a list of strings")
    items = cast(list[object], value)
    if not all(isinstance(item, str) for item in items):
        raise ConfigError(f"{key} must be a list of strings")
    return tuple(cast(list[str], items))


def _filters(table: Table) -> FiltersConfig:
    _check_keys(table, {"exclude", "extra_exclude", "per_file_cap", "count_unmerged_pr_lines"}, "[filters]")
    exclude = _strings(table["exclude"], "[filters].exclude") if "exclude" in table else DEFAULT_EXCLUDES
    exclude += _strings(table.get("extra_exclude", []), "[filters].extra_exclude")
    cap = table.get("per_file_cap", 1000)
    per_file_cap: int | None
    if cap is False:
        per_file_cap = None
    elif isinstance(cap, int) and not isinstance(cap, bool) and cap > 0:
        per_file_cap = cap
    else:
        raise ConfigError("[filters].per_file_cap must be a positive integer or false")
    unmerged = table.get("count_unmerged_pr_lines", False)
    if not isinstance(unmerged, bool):
        raise ConfigError("[filters].count_unmerged_pr_lines must be true or false")
    return FiltersConfig(exclude=exclude, per_file_cap=per_file_cap, count_unmerged_pr_lines=unmerged)


def _ai(table: Table) -> AiConfig:
    _check_keys(table, {"patterns"}, "[ai]")
    patterns = _strings(table["patterns"], "[ai].patterns") if "patterns" in table else DEFAULT_AI_PATTERNS
    for pattern in patterns:
        try:
            re.compile(pattern)
        except re.error as exc:
            raise ConfigError(f"[ai].patterns: invalid regex {pattern!r}: {exc}") from None
    return AiConfig(patterns=patterns)


def _report(table: Table) -> ReportConfig:
    _check_keys(table, {"period", "title", "top_repos", "compare_at", "charts", "image_size"}, "[report]")
    defaults = ReportConfig()
    period = table.get("period", defaults.period)
    if not isinstance(period, str) or period not in PERIODS:
        raise ConfigError(f"[report].period must be one of {', '.join(PERIODS)}")
    title = table.get("title", defaults.title)
    if not isinstance(title, str):
        raise ConfigError("[report].title must be a string")
    top = table.get("top_repos", defaults.top_repos)
    if isinstance(top, bool) or not isinstance(top, int) or not 1 <= top <= MAX_TOP_REPOS:
        raise ConfigError(f"[report].top_repos must be an integer from 1 to {MAX_TOP_REPOS}")
    charts = _strings(table["charts"], "[report].charts") if "charts" in table else defaults.charts
    unknown = [name for name in charts if name not in CHART_NAMES]
    if unknown:
        raise ConfigError(
            f"[report].charts: unknown chart {', '.join(unknown)} (choose from {', '.join(CHART_NAMES)})"
        )
    return ReportConfig(
        period=period,
        title=title,
        top_repos=top,
        compare_at=_compare_at(table.get("compare_at")),
        charts=charts,
        image_size=_image_size(table.get("image_size", list(defaults.image_size))),
    )


def _compare_at(value: object) -> date | None:
    if value is None:
        return None
    if isinstance(value, datetime):
        return value.date()
    if isinstance(value, date):
        return value
    if isinstance(value, str):
        try:
            return date.fromisoformat(value)
        except ValueError:
            pass
    raise ConfigError("[report].compare_at must be a date like 2025-02-24")


def _image_size(value: object) -> tuple[int, int]:
    if isinstance(value, list):
        items = cast(list[object], value)
        if len(items) == 2 and all(
            isinstance(item, int) and not isinstance(item, bool) and item > 0 for item in items
        ):
            return cast(int, items[0]), cast(int, items[1])
    raise ConfigError("[report].image_size must be [width, height] in pixels")
```

```python
def write_metrics(metrics: pd.DataFrame, path: Path) -> None:
    """Write long-format metrics; whole numbers without '.0', empty cells for NaN."""
    out = metrics[["period", "metric", "value", "repo"]].copy()
    out["value"] = [_format_value(v) for v in out["value"]]
    out.to_csv(path, index=False)


def _format_value(value: float) -> str:
    if pd.isna(value):
        return ""
    return str(int(value)) if float(value).is_integer() else f"{value:.6g}"


def read_metrics(path: Path) -> pd.DataFrame:
    if not path.exists():
        raise StoreError(f"{path} not found; run `gh-ledger summary` first")
    frame = pd.read_csv(path, dtype=str, keep_default_na=False)
    frame["value"] = pd.to_numeric(frame["value"].replace("", float("nan")))
    return frame
```

```python
from collections.abc import Mapping, Sequence

import pandas as pd

from gh_ledger.config import Config, FiltersConfig
from gh_ledger.filters import AiMatcher, PathFilter
from gh_ledger.model import Manifest

PERIOD_FREQ = {"week": "W-SUN", "month": "M", "quarter": "Q"}

    "prs_merged",
    "issues_opened",
    "direct_commits",

    "approvals",

    "lines_added",
    "lines_deleted",
    "lines_added_raw",
    "lines_deleted_raw",

)

    "prs_opened": "PRs opened",
    "prs_merged": "PRs merged",
    "issues_opened": "Issues opened",
    "direct_commits": "Direct commits",
    "reviews_given": "Reviews given",
    "approvals": "Approvals",
    "changes_requested": "Changes requested",
    "commented": "Review comments only",
    "comments": "Comments",
    "comments_on_others": "Comments on others' items",
    "lines_added": "Lines added (filtered)",
    "lines_deleted": "Lines deleted (filtered)",
    "lines_added_raw": "Lines added (raw)",
    "lines_deleted_raw": "Lines deleted (raw)",
    "lines_unfilterable": "Lines in truncated file lists",
    "repos_active": "Active repos",
    "ai_share_prs": "AI-assisted PRs",
    "ai_share_commits": "AI-assisted direct commits",
    "ai_share_comments": "AI-assisted comments",
}

SUMMARY_COLUMNS = (
    "prs_opened",
    "prs_merged",
    "issues_opened",
    "reviews_given",
    "comments",
    "lines_added",
    "lines_deleted",
    "ai_share_prs",
    "repos_active",
)


def period_starts(timestamps: pd.Series, period: str) -> pd.Series:
    """Map ISO timestamps to the first day (YYYY-MM-DD) of their UTC period."""
    parsed = pd.to_datetime(timestamps, utc=True, format="ISO8601").dt.tz_convert(None)
    return parsed.dt.to_period(PERIOD_FREQ[period]).dt.start_time.dt.strftime("%Y-%m-%d")


def all_periods(since: str, until: str, period: str) -> list[str]:
    periods = pd.period_range(start=since, end=until, freq=PERIOD_FREQ[period])
    return [p.start_time.strftime("%Y-%m-%d") for p in periods]


def compute_metrics(
    tables: Mapping[str, pd.DataFrame], manifest: Manifest, config: Config, period: str
) -> pd.DataFrame:
    """Every metric for every period in the manifest's range, in long format."""
    periods = all_periods(manifest.since, manifest.until, period)
    user = manifest.user.lower()
    prs, issues, reviews, comments, commits = (
        tables[name] for name in ("prs", "issues", "reviews", "comments", "commits")
    )
    on_others = reviews[reviews["pr_author"].str.lower() != user]
    counts: dict[str, pd.Series] = {
        "prs_opened": _count(prs, "created_at", period),
        "prs_merged": _count(prs[prs["state"] == "merged"], "merged_at", period),
        "issues_opened": _count(issues, "created_at", period),
        "direct_commits": _count(commits, "authored_at", period),
        "reviews_given": _count(on_others, "submitted_at", period),
        "approvals": _count(on_others[on_others["state"] == "approved"], "submitted_at", period),
        "changes_requested": _count(
            on_others[on_others["state"] == "changes_requested"], "submitted_at", period
        ),
        "commented": _count(on_others[on_others["state"] == "commented"], "submitted_at", period),
        "comments": _count(comments, "created_at", period),
        "comments_on_others": _count(
            comments[comments["parent_author"].str.lower() != user], "created_at", period
        ),
        "repos_active": _repos_active(tables, period),
    }
    line_totals, per_repo = _lines(tables, config.filters, period)
    counts.update(line_totals)
    matcher = AiMatcher(config.ai.patterns)
    shares = {
        "ai_share_prs": _ai_share(prs, "created_at", matcher, period),
        "ai_share_commits": _ai_share(commits, "authored_at", matcher, period),
        "ai_share_comments": _ai_share(comments, "created_at", matcher, period),
    }
    frames = [_long(name, counts[name].reindex(periods, fill_value=0), periods) for name in COUNT_METRICS]
    frames += [_long(name, shares[name].reindex(periods), periods) for name in SHARE_METRICS]
    per_repo = per_repo[per_repo["period"].isin(periods)]
    if not per_repo.empty:
        frames.append(per_repo.assign(metric="lines_changed")[["period", "metric", "value", "repo"]])
    return pd.concat(frames, ignore_index=True)


def wide(metrics: pd.DataFrame, names: Sequence[str]) -> pd.DataFrame:
    """Overall (non-repo) metrics as one row per period and one column per metric."""
    overall = metrics[(metrics["repo"] == "") & metrics["metric"].isin(list(names))]
    table = overall.pivot(index="period", columns="metric", values="value")
    return table.reindex(columns=list(names)).sort_index()


def summary_rows(metrics: pd.DataFrame) -> list[list[str]]:
    """The terminal summary: one row per period, SUMMARY_COLUMNS formatted for display."""
    table = wide(metrics, SUMMARY_COLUMNS)
    rows: list[list[str]] = []
    for period_start, row in table.iterrows():
        cells = [str(period_start)]
        for name in SUMMARY_COLUMNS:
            v = row[name]
            if pd.isna(v):
                cells.append("–")
            elif name in SHARE_METRICS:
                cells.append(f"{v:.0%}")
            else:
                cells.append(f"{int(v):,}")
        rows.append(cells)
    return rows


def _long(metric: str, values: pd.Series, periods: list[str]) -> pd.DataFrame:
    return pd.DataFrame(
        {"period": periods, "metric": metric, "value": values.to_numpy(dtype="float64"), "repo": ""}
    )


def _by_period(values: pd.Series, dates: pd.Series, period: str, how: str = "sum") -> pd.Series:
    if values.empty:
        return pd.Series(dtype="float64")
    return values.groupby(period_starts(dates, period).to_numpy()).agg(how)


def _count(frame: pd.DataFrame, column: str, period: str) -> pd.Series:
    dates = frame[column]
    dates = dates[dates != ""]
    return _by_period(pd.Series(1, index=dates.index), dates, period)


def _ints(frame: pd.DataFrame, *names: str) -> pd.DataFrame:
    return frame.astype(dict.fromkeys(names, "int64"))


def _lines(
    tables: Mapping[str, pd.DataFrame], filters: FiltersConfig, period: str
) -> tuple[dict[str, pd.Series], pd.DataFrame]:
    prs = _ints(tables["prs"], "additions", "deletions")
    if not filters.count_unmerged_pr_lines:
        prs = prs[prs["state"] == "merged"]
    commits = _ints(tables["commits"], "additions", "deletions")
    sources = pd.concat(
        [
            pd.DataFrame(
                {
                    "source": "pr",
                    "source_id": prs["id"],
                    "date": prs["merged_at"].where(prs["merged_at"] != "", prs["created_at"]),
                    "additions": prs["additions"],
                    "deletions": prs["deletions"],
                }
            ),
            pd.DataFrame(
                {
                    "source": "commit",
                    "source_id": commits["sha"],
                    "date": commits["authored_at"],
                    "additions": commits["additions"],
                    "deletions": commits["deletions"],
                }
            ),
        ],
        ignore_index=True,
    )
    files = _ints(tables["file_changes"], "additions", "deletions")
    files = files.merge(sources[["source", "source_id"]], on=["source", "source_id"], how="inner")

    listed = files.groupby(["source", "source_id"], as_index=False)[["additions", "deletions"]].sum()
    gaps = sources.merge(listed, on=["source", "source_id"], how="left", suffixes=("", "_listed"))
    gaps = gaps.fillna({"additions_listed": 0, "deletions_listed": 0})
    unfilterable = (
        gaps["additions"] + gaps["deletions"] - gaps["additions_listed"] - gaps["deletions_listed"]
    ).clip(lower=0)

    path_filter = PathFilter(filters.exclude)
    kept = files[~files["path"].map(path_filter.excluded).astype(bool)]
    if filters.per_file_cap is not None:
        cap = filters.per_file_cap
        kept = kept.assign(additions=kept["additions"].clip(upper=cap), deletions=kept["deletions"].clip(upper=cap))

    totals = {
        "lines_added": _by_period(kept["additions"], kept["date"], period),
        "lines_deleted": _by_period(kept["deletions"], kept["date"], period),
        "lines_added_raw": _by_period(sources["additions"], sources["date"], period),
        "lines_deleted_raw": _by_period(sources["deletions"], sources["date"], period),
        "lines_unfilterable": _by_period(unfilterable, gaps["date"], period),
    }
    per_repo = pd.DataFrame({"period": [], "repo": [], "value": []})
    if not kept.empty:
        changed = kept["additions"] + kept["deletions"]
        keys = [period_starts(kept["date"], period).to_numpy(), kept["repo"].to_numpy()]
        per_repo = (
            changed.groupby(keys).sum().astype("float64").rename_axis(["period", "repo"]).reset_index(name="value")
        )
    return totals, per_repo


def _repos_active(tables: Mapping[str, pd.DataFrame], period: str) -> pd.Series:
    stamps = (
        ("prs", "created_at"),
        ("issues", "created_at"),
        ("reviews", "submitted_at"),
        ("comments", "created_at"),
        ("commits", "authored_at"),
    )
    activity = pd.concat(
        [pd.DataFrame({"repo": tables[name]["repo"], "date": tables[name][col]}) for name, col in stamps],
        ignore_index=True,
    )
    activity = activity[activity["date"] != ""]
    return _by_period(activity["repo"], activity["date"], period, how="nunique")


def _ai_share(frame: pd.DataFrame, date_column: str, matcher: AiMatcher, period: str) -> pd.Series:
    co_authors = frame["co_authors"] if "co_authors" in frame.columns else pd.Series("", index=frame.index)
    flags = pd.Series(
        [
            matcher.matches(text, [entry for entry in co.split(";") if entry])
            for text, co in zip(frame["text"], co_authors, strict=True)
        ],
        index=frame.index,
        dtype="float64",
    )
    return _by_period(flags, frame[date_column], period, how="mean")
```

```python
"""Dated events drawn as markers on every time chart."""

from __future__ import annotations

from collections.abc import Iterable
from dataclasses import dataclass
from datetime import date, datetime
from pathlib import Path
from typing import cast

import yaml

KEYS = {"date", "label", "group", "url"}


class EventsError(Exception):
    """An events file is missing or malformed."""


@dataclass(frozen=True)
class Event:
    date: date
    label: str
    group: str = ""
    url: str = ""


def load_events(paths: Iterable[Path]) -> list[Event]:
    events = [event for path in paths for event in _load_file(path)]
    return sorted(events, key=lambda event: event.date)


def _load_file(path: Path) -> list[Event]:
    try:
        raw: object = yaml.safe_load(path.read_text(encoding="utf-8"))
    except FileNotFoundError:
        raise EventsError(f"Events file not found: {path}") from None
    except yaml.YAMLError as exc:
        raise EventsError(f"{path}: invalid YAML: {exc}") from None
    if raw is None:
        return []
    if not isinstance(raw, list):
        raise EventsError(f"{path}: expected a list of events")
    events: list[Event] = []
    for index, item in enumerate(cast(list[object], raw), start=1):
        where = f"{path} event {index}"
        if not isinstance(item, dict):
            raise EventsError(f"{where}: expected a mapping with date and label")
        entry = cast(dict[str, object], item)
        unknown = sorted(set(entry) - KEYS)
        if unknown:
            raise EventsError(f"{where}: unknown key {', '.join(unknown)}")
        events.append(
            Event(
                date=_date(entry.get("date"), where),
                label=_text(entry, "label", where, required=True),
                group=_text(entry, "group", where, required=False),
                url=_text(entry, "url", where, required=False),
            )
        )
    return events


def _date(value: object, where: str) -> date:
    if value is None:
        raise EventsError(f"{where}: missing date")
    if isinstance(value, datetime):
        return value.date()
    if isinstance(value, date):
        return value
    if isinstance(value, str):
        try:
            return date.fromisoformat(value)
        except ValueError:
            pass
    raise EventsError(f"{where}: date must be YYYY-MM-DD")


def _text(entry: dict[str, object], key: str, where: str, *, required: bool) -> str:
    value = entry.get(key)
    if value is None or value == "":
        if required:
            raise EventsError(f"{where}: missing {key}")
        return ""
    if not isinstance(value, str):
        raise EventsError(f"{where}: {key} must be text")
    return value
```

```python
"""Hide private repo names in report output."""

from __future__ import annotations

import pandas as pd


def redact_repos(metrics: pd.DataFrame, repos: pd.DataFrame) -> pd.DataFrame:
    """Rename private repos to `private repo N`, numbered by descending activity.

    Repos missing from `repos` are treated as private: when unsure, hide the name.
    """
    public = set(repos.loc[repos["is_private"] == "false", "repo"])
    activity = metrics[metrics["repo"] != ""].groupby("repo")["value"].sum()
    hidden = sorted((r for r in activity.index if r not in public), key=lambda r: (-activity[r], r))
    names = {repo: f"private repo {i}" for i, repo in enumerate(hidden, start=1)}
    return metrics.assign(repo=metrics["repo"].map(lambda r: names.get(r, r)))
```

```python
def _layout(fig: go.Figure, title: str) -> go.Figure:
    fig.update_layout(
        title={"text": title, "x": 0, "xanchor": "left"},
        template="plotly_white",
        paper_bgcolor=SURFACE,
        plot_bgcolor=SURFACE,
        font={"family": "system-ui, -apple-system, Segoe UI, sans-serif", "size": 13, "color": TEXT},
        hovermode="x unified",
        legend={"orientation": "h", "yanchor": "bottom", "y": 1.02, "xanchor": "right", "x": 1},
        margin={"l": 60, "r": 20, "t": 90, "b": 40},
        bargap=0.15,
    )
    fig.update_xaxes(showgrid=False, linecolor=GRID)
    fig.update_yaxes(gridcolor=GRID, zerolinecolor=GRID)
    return fig


def _bar_marker(color: str) -> dict[str, object]:
    # A thin surface-coloured outline separates stacked segments and adjacent bars.
    return {"color": color, "line": {"color": SURFACE, "width": 1.5}}

def activity(metrics: pd.DataFrame) -> go.Figure:

def repos(metrics: pd.DataFrame, top_n: int = 8) -> go.Figure:
    per_repo = metrics[(metrics["metric"] == "lines_changed") & (metrics["repo"] != "")]
    fig = go.Figure()
    if not per_repo.empty:
        totals = per_repo.groupby("repo")["value"].sum().sort_index().sort_values(ascending=False, kind="stable")
        top = list(totals.index[:top_n])
        grouped = per_repo.assign(repo=per_repo["repo"].where(per_repo["repo"].isin(top), OTHER_LABEL))
        table = grouped.pivot_table(index="period", columns="repo", values="value", aggfunc="sum", fill_value=0)
        table = table.reindex(sorted(metrics["period"].unique()), fill_value=0)
        names = top + ([OTHER_LABEL] if OTHER_LABEL in table.columns else [])
        x = _x(table)
        for i, name in enumerate(names):
            color = OTHER if name == OTHER_LABEL else SERIES[i]
            fig.add_trace(
                go.Bar(
                    x=x,
                    y=table[name],
                    name=name,
                    marker=_bar_marker(color),
                    hovertemplate=f"{name}: %{{y:,}}<extra></extra>",
                )
            )
    fig.update_layout(barmode="stack")
    fig.update_yaxes(title_text="Lines changed (filtered)")
    return _layout(fig, "Lines changed by repo")


def compare(metrics: pd.DataFrame, compare_at: date) -> go.Figure:
    names = [*COUNT_METRICS, *SHARE_METRICS]
    table = wide(metrics, names)
    starts = pd.to_datetime(table.index)
    cut = pd.Timestamp(compare_at)
    before = table[starts < cut].mean()
    after = table[starts >= cut].mean()
    labels = [METRIC_LABELS[name] for name in names]
    before_cells = [_fmt(before[name], share=name in SHARE_METRICS) for name in names]
    after_cells = [_fmt(after[name], share=name in SHARE_METRICS) for name in names]
    change_cells = [_change(before[name], after[name]) for name in names]
    fig = go.Figure(
        go.Table(
            header={
                "values": ["Metric (mean per period)", f"Before {compare_at}", f"From {compare_at}", "Change"],
                "align": "left",
                "fill_color": GRID,
                "font": {"color": TEXT},
            },
            cells={
                "values": [labels, before_cells, after_cells, change_cells],
                "align": "left",
                "fill_color": SURFACE,
                "font": {"color": TEXT},
            },
        )
    )
    fig.update_layout(height=120 + 28 * len(names))
    return _layout(fig, f"Before and after {compare_at}")


def _fmt(value: float, *, share: bool) -> str:
    if pd.isna(value):
        return "–"
    return f"{value:.0%}" if share else f"{value:,.1f}"


def _change(before: float, after: float) -> str:
    if pd.isna(before) or pd.isna(after) or before == 0:
        return "–"
    return f"{(after - before) / before:+.0%}"


def add_events(
    fig: go.Figure, events: Sequence[Event], start: date, end: date, *, labels: bool
) -> go.Figure:
    """Dashed vertical lines for events in [start, end], coloured by group, with hover markers."""
    shown = [event for event in events if start <= event.date <= end]
    groups = list(dict.fromkeys(event.group for event in shown))
    named = [group for group in groups if group]
    colors = {group: EVENT_COLORS[i] if i < len(EVENT_COLORS) else TEXT_MUTED for i, group in enumerate(named)}
    colors[""] = TEXT_MUTED
    for event in shown:
        x = event.date.isoformat()
        fig.add_vline(x=x, line={"dash": "dash", "width": 1, "color": colors[event.group]})
        if labels:
            fig.add_annotation(
                x=x,
                y=1,
                xref="x",
                yref="paper",
                text=event.label,
                textangle=-90,
                xanchor="right",
                yanchor="top",
                showarrow=False,
                font={"size": 10, "color": TEXT_MUTED},

                text=[f"{event.date:%Y-%m-%d} {event.label}" for event in members],
                hovertemplate="%{text}<extra></extra>",
            )
        )
    return fig
```

```python
# pyright: basic

"""Build the report's charts and headline numbers from metrics."""

from __future__ import annotations

from collections.abc import Callable, Sequence
from datetime import date

import pandas as pd
import plotly.graph_objects as go

from gh_ledger.config import ReportConfig
from gh_ledger.events import Event
from gh_ledger.report import charts

TIME_CHARTS = ("activity", "lines", "review_mix", "ai_share", "repos")
HEADLINE = (
    ("prs_merged", "PRs merged"),
    ("issues_opened", "Issues opened"),
    ("reviews_given", "Reviews given"),
    ("comments", "Comments"),
    ("lines_added", "Lines added"),
    ("lines_deleted", "Lines deleted"),
)
SIMPLE_CHARTS: dict[str, Callable[[pd.DataFrame], go.Figure]] = {
    "activity": charts.activity,
    "lines": charts.lines,
    "review_mix": charts.review_mix,
    "ai_share": charts.ai_share,
}


def build_charts(
    metrics: pd.DataFrame, config: ReportConfig, events: Sequence[Event], start: date, end: date
) -> list[tuple[str, go.Figure]]:
    """Charts in configured order. Event labels go on the first time chart only."""
    figures: list[tuple[str, go.Figure]] = []
    for name in config.charts:
        if name == "compare":
            if config.compare_at is not None:
                figures.append((name, charts.compare(metrics, config.compare_at)))
            continue
        fig = charts.repos(metrics, config.top_repos) if name == "repos" else SIMPLE_CHARTS[name](metrics)
        first = not any(existing in TIME_CHARTS for existing, _ in figures)
        figures.append((name, charts.add_events(fig, events, start, end, labels=first)))
    return figures


def headline(metrics: pd.DataFrame) -> list[tuple[str, str]]:
    """Totals over the whole range for the strip above the charts."""
    totals = metrics[metrics["repo"] == ""].groupby("metric")["value"].sum()
    return [(label, f"{int(totals.get(name, 0)):,}") for name, label in HEADLINE]
```

```python
"""Assemble the self-contained HTML report."""

from __future__ import annotations

import html
from collections.abc import Sequence

import plotly.graph_objects as go

STYLE = """
:root { color-scheme: light; --surface: #fcfcfb; --text: #0b0b0b; --muted: #52514e; --rule: #e7e6e2; }
* { box-sizing: border-box; }

       font: 15px/1.5 system-ui, -apple-system, "Segoe UI", sans-serif; }
main { max-width: 1240px; margin: 0 auto; padding: 32px 24px 64px; }
h1 { font-size: 28px; margin: 0 0 4px; }
.subtitle { color: var(--muted); margin: 0 0 24px; }
.headline { display: flex; flex-wrap: wrap; gap: 12px; margin-bottom: 32px; }
.tile { flex: 1 1 150px; border: 1px solid var(--rule); border-radius: 8px; padding: 12px 16px; }
.tile .value { font-size: 26px; font-weight: 600; font-variant-numeric: tabular-nums; }
.tile .label { color: var(--muted); font-size: 13px; }
.chart { margin: 0 0 40px; border-top: 1px solid var(--rule); padding-top: 16px; }
"""


def build_html(
    title: str,
    subtitle: str,
    headline: Sequence[tuple[str, str]],
    charts: Sequence[tuple[str, go.Figure]],
) -> str:
    tiles = "\n".join(
        f'<div class="tile"><div class="value">{html.escape(value)}</div>'
        f'<div class="label">{html.escape(label)}</div></div>'
        for label, value in headline
    )
    sections: list[str] = []
    for i, (name, fig) in enumerate(charts):
        div = fig.to_html(
            full_html=False,
            include_plotlyjs=i == 0,  # inline the library once; the file works offline
            div_id=f"plot-{name}",
            config={"displaylogo": False, "responsive": True},
        )
        sections.append(f'<section class="chart" id="chart-{name}">\n{div}\n</section>')
    body = "\n".join(sections)
    return f"""<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{html.escape(title)}</title>
<style>{STYLE}</style>
</head>
<body>
<main>
<h1>{html.escape(title)}</h1>
<p class="subtitle">{html.escape(subtitle)}</p>
<div class="headline">
{tiles}
</div>
{body}
</main>
</body>
</html>
"""
```

```python
# pyright: basic

"""PNG and SVG export of each chart, via the optional kaleido extra."""

from __future__ import annotations

from collections.abc import Sequence
from importlib.util import find_spec
from pathlib import Path

import plotly.graph_objects as go


def export_images(
    charts: Sequence[tuple[str, go.Figure]], out_dir: Path, size: tuple[int, int]
) -> str | None:
    """Write `<name>.png` and `<name>.svg` per chart. Returns why images were skipped, or None."""
    if find_spec("kaleido") is None:
        return "kaleido is not installed; install gh-ledger[images] for PNG/SVG export"
    out_dir.mkdir(parents=True, exist_ok=True)
    width, height = size
    try:
        for name, fig in charts:
            for extension in ("png", "svg"):
                fig.write_image(out_dir / f"{name}.{extension}", width=width, height=height)
    except Exception as exc:  # kaleido drives a local Chrome; any failure there means no images
        return f"image export failed ({exc}); kaleido needs Chrome, which `plotly_get_chrome` can install"
    return None
```

```python
@app.command()
def report(
    data: Annotated[Path, typer.Option(help="Data directory written by fetch and summary.")],
    out: Annotated[Path, typer.Option(help="Directory for report.html and charts/.")],
    config: Annotated[Path | None, typer.Option(help="ledger.toml with [report] settings.")] = None,
    events: Annotated[list[Path] | None, typer.Option(help="Event YAML file. Repeatable.")] = None,
    redact_private: Annotated[
        bool, typer.Option(help="Show private repos as 'private repo N' everywhere.")
    ] = False,
) -> None:
    """Render DATA/metrics.csv as OUT/report.html plus PNG/SVG charts."""
    try:
        cfg = load_config(config)
        manifest = read_manifest(data)
        if manifest is None:
            raise StoreError(f"{data} has no manifest.json; run `gh-ledger fetch` first")
        metrics = read_metrics(data / "metrics.csv")
        if redact_private:
            metrics = redact_repos(metrics, load_table(data, "repos"))
        overlay = load_events(events or [])
    except (ConfigError, EventsError, StoreError) as exc:
        fail(exc)
    start, end = date.fromisoformat(manifest.since), date.fromisoformat(manifest.until)
    figures = build_charts(metrics, cfg.report, overlay, start, end)
    out.mkdir(parents=True, exist_ok=True)
    page = build_html(cfg.report.title, f"{manifest.user} · {manifest.since} to {manifest.until}", headline(metrics), figures)
    (out / "report.html").write_text(page, encoding="utf-8")
    err_console.print(f"Wrote {out / 'report.html'}")
    skipped = export_images(figures, out / "charts", cfg.report.image_size)
    if skipped:
        err_console.print(f"[yellow]Images skipped:[/] {escape(skipped)}")
    else:
        err_console.print(f"Wrote {len(figures) * 2} images to {out / 'charts'}")
```
